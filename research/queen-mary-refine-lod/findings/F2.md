# F2: 中距 50–200 m 灰盒可读性层次

## Findings

### [1] HMS Queen Mary (1913) recognition against Lion-class sisters depended on secondary-armament deck height, centre-funnel roundness, stern walkway presence, and pole-vs-tripod mast — not surface fittings.
- quote: "Visually she was hard to distinguish from the Lion class but with the secondary armament on a single deck, the centre funnel was rounder than in the Lion class and she had a stern walkway that was lacking in her near sisters. Originally fitted with a pole mast this was later altered to a tripod mast."
- url: https://www.worldwar1.co.uk/battlecruiser/hms-queen-mary.html/
- source_type: secondary
- published: unknown (site ©1998–2026)
- confidence: high

### [2] Funnel count/profile was a primary warship identity channel in WWI naval deception: SMS Emden mounted an additional false funnel specifically to imitate British county-class cruisers.
- quote: "With an additional false funnel to imitate British county-class cruisers, the Emden at daybreak of October 28 passed the picket-boat outside the harbor unchallenged"
- url: https://www.gutenberg.org/files/24797/24797-h/24797-h.htm
- source_type: primary
- published: 1920 (Gutenberg release 2008-03-10; Stevens & Westcott, USNA)
- confidence: high

### [3] At engagement ranges ships were identified by sky silhouette; damage to funnels/masts destroyed recognition identity (Tsushima, Suvaroff "scarcely any one would have taken her for a ship").
- quote: "her forward funnel down, and steering gear jammed. \"She was so battered,\" wrote a Japanese observer, \"that scarcely any one would have taken her for a ship.\""
- url: https://www.gutenberg.org/files/24797/24797-h/24797-h.htm
- source_type: primary
- published: 1920 (Gutenberg release 2008-03-10)
- confidence: high

### [4] WWI period type-plates (Jane's-style) reduce capital-ship identity to broadside profile blocks — hull, funnels, masts, turret layout — not material/detail (illustrations: Derfflinger p.390, Lion p.393, Iron Duke p.399, Koenig p.402).
- quote: "Type of German Battle Cruiser: The Derflinger … Type of British Battle Cruiser: The Lion … Type of British Battleship: The Iron Duke … Type of German Battleship: the Koenig"
- url: https://www.gutenberg.org/files/24797/24797-h/24797-h.htm
- source_type: primary
- published: 1920 (Gutenberg release 2008-03-10)
- confidence: high

### [5] HMS Queen Mary overall length is 213.36 m (698 ft waterline / 703 ft 6 in OA), beam 89 ft (~27.13 m) — LOD Object Size and screen-height thresholds must be calibrated to this scale, not a 1 m default.
- quote: "dbo:length — 213.360000 (xsd:double) … dbo:shipBeam — 27.127200 (xsd:double) … Length 698 feet waterline 703 feet 6 inches overall, beam 89 feet"
- url: https://dbpedia.org/page/HMS_Queen_Mary
- source_type: primary
- published: extracted from en.wikipedia HMS_Queen_Mary (oldid 1312408052); worldwar1.co.uk concurrent
- confidence: high

### [6] Queen Mary silhouette-critical massing: 8×13.5in in 4 twin turrets (superfiring fore/aft), 16×4in singles on a single deck, 2×21in TT — main-battery count/arrangement and secondary deck level are mid-range identity; individual secondary barrels are not.
- quote: "Armament: 8 x 13.5in 45cal MK V (4 x 2), 16 x 4in (16 x 1), 4 x 3 pounder, 2 x 21in TT"
- url: https://www.worldwar1.co.uk/battlecruiser/hms-queen-mary.html/
- source_type: secondary
- published: unknown
- confidence: high

### [7] Unity 6.6 LOD Group transitions are driven by Transition (% Screen Size) — object screen-height percentage — not absolute camera meters; Unity only displays the live camera distance in meters beside that percentage after Object Size is set.
- quote: "Transition (% Screen Size) — Sets the height of the object when the LOD level transitions to the next LOD level, as a percentage of the screen height. To the right of this property, Unity displays the camera distance at which the LOD level transitions, in meters. … Object Size — Sets the size of the object in meters for LOD Group calculations."
- url: https://docs.unity3d.com/Manual/class-LODGroup.html
- source_type: primary
- published: Unity Manual Unity 6.6 (6000.6), built 2026-09-16
- confidence: high

### [8] For a 213.36 m battlecruiser, LOD Group Object Size must be set to the asset's real metres (or scaled equivalent); default Object Size=1 treats the hull as a 1 m cube and pushes all LOD transitions absurdly close to camera.
- quote: "Sets the size of the object in meters for LOD Group calculations. For example, if you change Object Size from 1 to 0.6, an object that has a screen height of 100% is now considered to have a screen height of 60%. As a result, the transitions to smaller screen height percentages and less detailed LOD levels occur closer to the camera."
- url: https://docs.unity3d.com/Manual/class-LODGroup.html
- source_type: primary
- published: Unity 6.6 (6000.6), 2026-09-16
- confidence: high

### [9] LOD Group is the correct Unity path for greybox warship LODs because each level can drop Mesh Renderers, materials/submeshes (draw calls), and material complexity — not only triangle count via index buffers.
- quote: "When authoring LOD objects, you have the following optimization options for each LOD: Create a less detailed mesh. Reduce the number of materials or submeshes, which reduces the number of draw calls. Optimize settings on materials. Optimize Mesh Renderer settings."
- url: https://docs.unity3d.com/Manual/LevelOfDetail.html
- source_type: primary
- published: Unity 6.6 (6000.6), 2026-09-16
- confidence: high

### [10] Unity Mesh LOD auto-simplifier is poorly suited to hard-surface multi-piece warship meshes: it "works best for organic shapes or relatively flat surfaces" and "might produce undesired results on meshes with a high curvature or meshes that consist of many disconnected pieces" — use manual LOD Group authoring for Queen Mary massing layers.
- quote: "The LOD generator works best for organic shapes or relatively flat surfaces with a high vertex density, for example: living creatures, rocks, sculptures, and so on. The generator might produce undesired results on meshes with a high curvature or meshes that consist of many disconnected pieces."
- url: https://docs.unity3d.com/Manual/lod/mesh-lod-generator.html
- source_type: primary
- published: Unity 6.6 (6000.6), 2026-09-16
- confidence: high

### [11] Unity Mesh LOD generator mechanics for calibration: requires ≥256 triangles to start; each subsequent LOD stores ~half the previous index count; generation stops near ~64 triangles or when no more vertices can be omitted; all LODs share the original vertex buffer.
- quote: "The original mesh must have at least 256 triangles for the simplification process to start. … Each subsequent LOD contains approximately half the number of indices as the previous one. … In most cases the minimum number is around 64. … All LODs reuse the same vertex buffer."
- url: https://docs.unity3d.com/Manual/lod/mesh-lod-generator.html
- source_type: primary
- published: Unity 6.6 (6000.6), 2026-09-16
- confidence: high

### [12] Project-wide Quality>Level of Detail exposes LOD Bias (distance scale, example: Bias=2 moves a 50%-screen transition to 25% screen-height distance), Maximum LOD Level (build strip), and Mesh LOD Threshold (favors less-detailed LODs when increased) — fleet-screen quality tiers should tune these, not per-ship mesh edits.
- quote: "LOD Bias — Adjusts the detail level of GameObjects by scaling the distances where Unity transitions between different level of detail (LOD) meshes. … if you set LOD Bias to 2, a transition to a lower-quality LOD level that usually happens at 50% distance now happens at 25% distance (50% / 2 = 25%). … Mesh LOD Threshold — Affects how Unity selects a LOD index to render. Increasing the value makes Unity favor less detailed LODs"
- url: https://docs.unity3d.com/Manual/class-QualitySettings.html
- source_type: primary
- published: Unity 6.6 (6000.6), 2026-09-16
- confidence: high

### [13] LOD Group import convention: mesh suffix _LODX (X = index), max eight LOD levels, LOD0 most detailed/closest; project Maximum LOD Level and LOD Bias are the quality-tier knobs; Cross Fade (Fade Transition Width) softens silhouette pops when funnel/mast LODs swap.
- quote: "Add the suffix _LODX to the name of each mesh, where X represents the LOD index. For example, use ExampleMeshName_LOD0 for the most detailed LOD. The LOD Group component accepts a maximum of eight LOD levels. … To make LOD transitions smooth, enable LOD cross-fading. … A smaller value delays the beginning of the transition and makes the transition shorter."
- url: https://docs.unity3d.com/Manual/lod-group-configure.html
- source_type: primary
- published: Unity 6.6 (6000.6), 2026-09-16
- confidence: high

### [14] At 50–200 m observation for a 213.36 m hull (60° HFOV), the ship still subtends a large fraction of the view (≈2×200·tan30° ≈ 231 m visible width vs 213 m length) — mid-range greybox LODs must retain hull L/B profile, 4-funnel massing, main-turret count/arrangement, superstructure blocks, and mast type; individual 4in secondaries, boats, rails, cables, and deck fittings are the first layers safe to drop to distant LODs.
- quote: "Length 698 feet waterline 703 feet 6 inches overall, beam 89 feet … 8 x 13.5in 45cal MK V (4 x 2), 16 x 4in (16 x 1) … Transition (% Screen Size) … as a percentage of the screen height."
- url: https://www.worldwar1.co.uk/battlecruiser/hms-queen-mary.html/ + https://docs.unity3d.com/Manual/class-LODGroup.html + https://dbpedia.org/page/HMS_Queen_Mary
- source_type: primary
- published: dimensions from worldwar1/DBpedia; screen model from Unity 6.6 docs
- confidence: medium
