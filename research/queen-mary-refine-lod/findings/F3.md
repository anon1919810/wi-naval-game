# F3: Unity LODGroup 屏幕高度阈值与 lodBias

## Findings

### [1] Unity 2022.3 LODGroup 层级阈值定义为「GameObject 屏幕空间高度 / 屏幕总高度」的比率，不是世界距离。
- quote: "The percentage that appears in each LOD level box represents the threshold at which that level becomes active, based on the ratio of the GameObject's screen space height to the total screen height."
- url: https://docs.unity3d.com/2022.3/Documentation/Manual/class-LODGroup.html
- source_type: primary
- published: 2026-07-02 (doc publication date on page; page originally published 2018-02-08)
- confidence: high

### [2] Scripting API `LOD.screenRelativeTransitionHeight` 是唯一正式的可编程切换阈值字段，取值范围 [0-1]，对应代码中当前 0.20/0.08/0.03/0.01 这类默认值。
- quote: "The screen relative height to use for the transition [0-1]."
- url: https://docs.unity3d.com/2022.3/Documentation/ScriptReference/LOD-screenRelativeTransitionHeight.html
- source_type: primary
- published: 2026-07-02
- confidence: high

### [3] `QualitySettings.lodBias` 是全局 LOD 切换距离乘数：值 ≥1 时更晚才降到更低 LOD（高质量保持更久）；值在 0–1 时更早降级。
- quote: "A LOD Bias value between 0 and 1 results in Unity selecting lower-quality LODs at closer distances than normal. A value of 1 or more results in Unity selecting lower-quality LODs at farther distances than normal, so GameObjects retain higher quality for longer."
- url: https://docs.unity3d.com/2022.3/Documentation/Manual/class-QualitySettings.html
- source_type: primary
- published: 2026-07-02
- confidence: high

### [4] Quality Settings 文档给出了 bias=2 的换算示例：作者阈值 50% 会按 50%/2=25% 生效——即 bias 会把屏幕高度阈值「压低」，从而推迟低模切换；这与项目中「bias 常为 2」时仍写 0.20/0.08/0.03/0.01 的现状直接相关：实际生效阈值约为 0.10/0.04/0.015/0.005。
- quote: "For example, if you set LOD Bias to 2, a transition to a lower-quality LOD level that usually happens at 50% distance now happens at 25% distance (50% / 2 = 25%)."
- url: https://docs.unity3d.com/2022.3/Documentation/Manual/class-QualitySettings.html
- source_type: primary
- published: 2026-07-02
- confidence: high

### [5] Scripting API 对 lodBias 的语义表述与 Quality 文档一致：更大值 = 更远视距才选低分辨率 LOD。
- quote: "Global multiplier for the LOD's switching distance. A larger value leads to a longer view distance before a lower resolution LOD is picked."
- url: https://docs.unity3d.com/2022.3/Documentation/ScriptReference/QualitySettings-lodBias.html
- source_type: primary
- published: 2026-07-02
- confidence: high

### [6] LODGroup Inspector 在 `Lod Bias ≠ 1` 时会明确警告：选择条上的 Camera 位置/百分比预览可能与真实切换点不一致——标定阈值时不能只信预览 playhead。
- quote: "If the Lod Bias property is not set to 1, the Camera position might not match the position where each LOD level actually transitions from the next. In this case, a warning message appears below the selection bar."
- url: https://docs.unity3d.com/2022.3/Documentation/Manual/class-LODGroup.html
- source_type: primary
- published: 2026-07-02
- confidence: high

### [7] `LODGroup.size` 是「local space」下的物体尺寸；`localReferencePoint` 是 LOD 距离计算的局部参考点。对 213.4 m 长的战列舰 greybox，阈值标定应以包围盒高度（或 RecalculateBounds 后的 size）为准，而不是把船长直接当 size。
- quote: "The size of the LOD object in local space." / "The local reference point against which the LOD distance is calculated."
- url: https://docs.unity3d.com/2022.3/Documentation/ScriptReference/LODGroup-size.html ; https://docs.unity3d.com/2022.3/Documentation/ScriptReference/LODGroup-localReferencePoint.html
- source_type: primary
- published: 2026-07-02
- confidence: high

### [8] 屏幕高度占用率可由官方视锥高度公式换算：`frustumHeight = 2 * distance * tan(fov*0.5*Deg2Rad)`；相对高度 ≈ `LODGroup.size / frustumHeight`。这是把 50–200 m 战术视距与 ~1.7 km 舰队视距映射到 [0-1] 阈值的可替换标定公式。
- quote: "var frustumHeight = 2.0f * distance * Mathf.Tan(camera.fieldOfView * 0.5f * Mathf.Deg2Rad);"
- url: https://docs.unity3d.com/2022.3/Documentation/Manual/FrustumSizeAtDistance.html
- source_type: primary
- published: 2026-07-02
- confidence: high

### [9] LODGroup 单实例最多 8 个 LOD 层级；LOD0 最近最细，可编程用 `LODGroup.SetLODs`/`GetLODs` 写入可替换阈值数组，`RecalculateBounds` 在改 LOD 网格后重算包围体（文档标明较慢、勿频繁调用）。
- quote: "The LOD Group component accepts a maximum of eight LOD levels. LOD 0 is the closest to the Camera, and therefore the most detailed LOD level." / "Recalculate the bounding region for the LODGroup (Relatively slow, do not call often)."
- url: https://docs.unity3d.com/2022.3/Documentation/Manual/LevelOfDetail.html ; https://docs.unity3d.com/2022.3/Documentation/ScriptReference/LODGroup.RecalculateBounds.html
- source_type: primary
- published: 2026-07-02
- confidence: high

### [10] URP 14（Unity 2022.3 配套）不单独提供 LOD Bias；URP Asset 只提供 Quality 段的 `LOD Cross Fade` 开关与 `LOD Cross Fade Dithering Type`（Bayer Matrix / Blue Noise）。lodBias 仍走全局 Quality Settings；标定阈值时需同时决定跨 LOD 淡入淡出策略。
- quote: "LOD Cross Fade — Use this property to enable or disable the LOD cross-fade." / "LOD Cross Fade Dithering Type — ... Bayer Matrix: better performance than the Blue Noise option, but has a repetitive pattern. Blue Noise: uses a precomputed blue noise texture..."
- url: https://docs.unity3d.com/Packages/com.unity.render-pipelines.universal@14.0/manual/universalrp-asset.html
- source_type: primary
- published: unknown (URP 14.0.12 package docs)
- confidence: high

### [11] 跨 LOD 切换可按时间动画或按位置宽度：`animateCrossFading` + 全局 `LODGroup.crossFadeAnimationDuration`，或关闭动画后用 `LOD.fadeTransitionWidth`（[0-1]，表示当前 LOD 区间长度的比例）定义过渡带；多舰舰队视图建议用窄过渡带避免 15 艘船同步 pop。
- quote: "Width of the cross-fade transition zone (proportion to the current LOD's whole length) [0-1]. Only used if it's not animated." / "The cross-fading animation duration in seconds."
- url: https://docs.unity3d.com/2022.3/Documentation/ScriptReference/LOD-fadeTransitionWidth.html ; https://docs.unity3d.com/2022.3/Documentation/ScriptReference/LODGroup-crossFadeAnimationDuration.html
- source_type: primary
- published: 2026-07-02
- confidence: high

### [12] 与 mesh LOD 正交的官方补充手段：`Camera.layerCullDistances`（32 长度 float 数组，0 表示用 far plane）可用于舰队远景下对次要层（小艇、细节层）提前剔除；`QualitySettings.maximumLODLevel` 可从 build 剔除更细 LOD 网格。这些应与可替换阈值一起进入配置，而不是只改 0.20/0.08/0.03/0.01。
- quote: "You can set up some Layers to use smaller culling distances using layerCullDistances. This is very useful to cull small objects early on..." / "Sets the lowest LOD level the project uses. Unity removes LOD meshes below the Maximum LOD level from the build..."
- url: https://docs.unity3d.com/2022.3/Documentation/ScriptReference/Camera-layerCullDistances.html ; https://docs.unity3d.com/2022.3/Documentation/Manual/class-QualitySettings.html
- source_type: primary
- published: 2026-07-02
- confidence: high

### [13] ShaderLab SubShader `LOD` 值与 LODGroup 距离 LOD 无关：文档明确「shader LOD does not relate to distance from the Camera, and Unity does not calculate shader LOD automatically」——不要把 Shader.maximumLOD 与本主题阈值混为一谈。
- quote: "Note: Although this technique is named after the LOD feature for rendering meshes, there are important differences: shader LOD does not relate to distance from the Camera, and Unity does not calculate shader LOD automatically."
- url: https://docs.unity3d.com/2022.3/Documentation/Manual/SL-ShaderLOD.html
- source_type: primary
- published: 2026-07-02
- confidence: high

### [14] 调试/标定可用 `LODGroup.ForceLOD(int index)` 强制层级，index < 0 恢复正常 LOD 处理——适合在 50–200 m 与 1.7 km 两套相机下逐一验证各级 greybox 外观后再锁阈值。
- quote: "ForceLOD(int index) ... Passing index < 0 will return to standard LOD processing."
- url: https://docs.unity3d.com/2022.3/Documentation/ScriptReference/LODGroup.ForceLOD.html
- source_type: primary
- published: 2026-07-02
- confidence: high

### [15] 用官方 frustum 公式对当前默认阈值 + lodBias=2 做可替换标定推算（示例：若 LODGroup.size 取舰体灰盒高度约 40 m、垂直 FOV 60°）：相对高度 relH = size / (2·d·tan30°)；50 m → relH≈0.69（bias 后≈1.39，LOD0）；200 m → relH≈0.17（bias 后≈0.35，仍偏 LOD0/LOD1 边界取决于阈值）；1700 m → relH≈0.020（bias 后≈0.041，落入 0.08–0.03 档即 LOD2）。结论：现有 0.20/0.08/0.03/0.01 + bias=2 在 1.7 km 舰队视图会较快压到中低模，但战术 50–200 m 多舰同屏时仍可能长期停在 LOD0；阈值与 bias 需解耦配置以便两种视图分别校准。
- quote: "var frustumHeight = 2.0f * distance * Mathf.Tan(camera.fieldOfView * 0.5f * Mathf.Deg2Rad);" （推算基于该 primary 公式 + [3][4] bias 语义，非 Unity 官方推荐表）
- url: https://docs.unity3d.com/2022.3/Documentation/Manual/FrustumSizeAtDistance.html
- source_type: primary
- published: 2026-07-02
- confidence: medium
