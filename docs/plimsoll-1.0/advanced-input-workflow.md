# 高级输入与破损研究操作

本轮把已有计算方法接到表单，不增加新的物理模型。先保存修订，再提交所选工况的计算；请求草稿只属于当前工作台，重开项目后重新选择。完整结果固定保存输入快照与请求指纹。

## 高级输入

- **性能与工况 → 阻力研究场景**：创建命名场景，选择已有 Holtrop–Mennen 或 Taylor–Gertler 来源轴方法，声明输入、来源与估算状态。附体“未知”“明确不存在”“存在并声明数据”各有不同含义；空附体列表明确表示不存在。首侧推也必须声明存在状态。方法所需的来源轴数据使用已有核心数据，不在浏览器中伪造表格。
- **重量与载荷 → 系统物理质量模型**：选择已绑定账本的系统叶，添加体积×密度、板面积×厚度×密度、计数×单具质量或弹药质量模型。选择比较条目、显式容差、模型来源和估算状态；估算模型的每个输入还需自己的来源与估算状态。计数只用装舰数量或有依据的整数，不能拿单舷炮数乘全舰质量。
- **火炮武备 → 炮页行**：炮身、炮座与弹药分别绑定已有账本条目。移除行不丢弃该系统尚未分配的绑定。炮座行可用于旋转装甲拆分。物理模型只产生只读比较与待复核提案，不自动修改重量。
- **破损研究 → 项目舱室几何**：登记有来源的范围、位置和渗透率。这也是主装甲带研究可选舱段的来源。ID 建立后保持不变；被主带研究或破损预设引用的舱室，先解除引用才可删除。舱室几何不自动产生质量。

未知留空；显式 0 是已知零值。保存草稿不代表输入已完整，核心仍对实际研究进行适用性与输入校验。

## 破损研究

1. 在“破损研究”新建场景，声明进水时长、时间步长、场景来源与估算状态。
2. 声明海水节点和密度。淡水研究需同时显式填写请求环境密度，使海水、舱室、连接及本次浮态/剩余稳性使用同一密度。
3. 添加场景舱室；也可以显式复制项目舱室几何。复制不带入水量。逐舱填写长宽高、位置、渗透率、自由液面、液体密度和**附加初始水体积**。基准账本已含的水不能重复填入；舱室 ID 不可与账本条目同名。参与开启连接的舱室必须声明“存在自由液面”：现有进水方法采用通气液面模型，“无自由液面”是锁定重心代理，不能用于该流动研究；关闭阀门也不等于消除自由液面。
4. 添加连接，选择起终节点，声明坐标、面积、流量系数 Cd、开启状态、密度和来源。面积/Cd 的已知 0 表示零流量。有限开口高度检查是显式可选项，不勾选时不添加此输入。
5. 声明开口知识：沿用项目定义、明确无开放点，或逐点声明。缺开口资料不能被当成不存在开口。可增删多个开口点，保留开启状态、坐标、来源和估算标记。
6. 保存修订；在“本次破损计算请求”选择场景，可声明步数上限、重试次数、重力与剩余 GZ 采样/快照。未选场景不请求破损阶段。无效或不完整请求会给出原因，不能提交伪有效研究。
7. 点击“运行计算”，通过原有队列页查看进度、取消或失败原因；完成/部分完成后打开报告。破损结果显示所属场景、停止原因、请求与实际时长、守恒误差、进水量/姿态序列和剩余 GZ。长轨迹界面抽样最多 12 个状态，完整序列保留在原始结果。

实际推进时间短于请求时长，可能是水力平衡、开口事件或模型边界，必须结合停止原因判断。部分轨迹不等于完成全部时长；剩余 GZ 也不是安全认证。改变当前场景选择或未提交的请求不会重新计算旧结果；页面标明旧结果的场景和请求身份。

## 显示单位约定

在“船型与几何 → 显示偏好”选择长度 m/ft、质量 t/kg/long ton、功率 kW/shp、航速 kn/m/s 和角度 °/rad。偏好保存为项目修订；无偏好的旧项目使用规范单位。字段旁显示当前单位，输入也按该单位解释，包括以 mm 存储的装甲厚度和以 kg 存储的弹丸质量。

换算只发生在显示层和输入解释层：输入换回字段规范单位后保存；结果只转换展示，不修改已保存计算。来源、估算、未知与零不参与数值换算。面积和体积按长度的平方/立方处理；燃料日耗的质量分量换算，但分母始终为 day。时间、密度、黏度、重力、力等继续明确显示规范单位。阻力 kN 是力，不能按航速 kn 换算。非法采样会阻止提交，不会沿用上一次有效采样静默运行。

原始项目 JSON、API 请求、结果 JSON 和 CSV 均保持规范单位及原字段名。它们不是屏幕显示数值的逐字复制。报告显示偏好来自该运行的输入快照；报告顶部可临时切换显示单位，无需保存修订或重新求解。

## 保留边界

型线点阵、任意扩展字段和未被既有模型覆盖的内部结构仍可通过项目 JSON/API 编辑。本轮不宣称任意项目完全无需 JSON，不补造 Queen Mary 资料，不增加 CFD、穿甲、爆炸、结构强度或游戏接入。计算阶段状态、史实准备度和网站部署状态分别判断。
