# Queen Mary 输入资料准备度与下一步

更新：2026-09-23。本文核对当前生成的 `tools/plimsoll/cases/projects/queen_mary_1913.project.json` 和 [案例来源清单](case-sources.md)。**计算接口可运行**与**该舰输入已获史实验证**是两件事：当前项目是有来源说明的工程代理案例，不能把其结果当作 Queen Mary 的实船证明。191 条七页观察记录的功能绑定状态见 [逐项表](evidence/seven-page-binding-proposal.json)，不能用该表替代具体舰船的数据准备度。

## 当前可用的计算与输入边界

项目已经能以正常和满载工况运行重量、浮态、稳性、阻力、功率、续航和简化破损计算。基础船型由估算偏移表生成，舱室和开口是建模代理；固定装甲面积来自模型包围尺寸，主炮座重量采用 Mark II 代理并假定包含旋转装甲及部分扬弹机构。正常和满载的燃料、给水、生活载荷也是明示的研究情景，不是船厂重量报告。当前算出的正常 27,851.62934079477 t、满载 31,926.26200617077 t 是可复现的模型输出，位数不代表史实精度。

后续加入的两个可选结果刻意保持未知：`systems.armour.fixed.deck_coverage` 需要有来源的受保护平面面积和参考平面面积；`systems.weapons.main.rotating_armour_component` 需要与已计入炮座账本一致的旋转装甲独立质量。当前 Queen Mary 项目没有这两组可靠输入。已有装甲板的展开面积估算或炮座总质量不能替代它们，也不能把未知填成零。最小主装甲带覆盖长度同样需要各关键舱室的真实纵向范围与明确余量；代理舱室只能用于方法示例，不能证明史实覆盖。

## 按结果影响排序的补证清单

| 优先级 | 需取得的原始资料与最小核对内容 | 目前被限制的结果 | 收到资料后的处理 |
| --- | --- | --- | --- |
| 1 | 船厂或海军部重量报告：项目质量、吨制、统计日期、各项包含边界 | 全舰质量分项、排水量对照及所有以质量为基础的结果 | 对齐唯一账本条目，查重与漏项；只替换有据可查的项 |
| 1 | 实船型线或可量尺的站位/水线表，并注明基线与吃水定义 | 静水力、浮态、稳性、阻力的几何可信度 | 用现有 L1 导入和解析校验，不按照片外形反求截面 |
| 1 | 重量矩或倾斜试验资料，给出载荷条件、纵向及垂向重心 | 纵倾、GM/GZ、横摇和破损残余稳性 | 与对应重量账本及同一工况绑定，重新计算而非拟合输出 |
| 2 | 装甲配置表：固定/旋转边界、厚度、各段实际展开面积，以及装甲甲板受保护和参考**平面**面积 | 装甲质量校核、甲板覆盖率、主带长度研究 | 分别核对质量面积与平面覆盖面积；没有独立平面面积时继续 `unavailable` |
| 2 | Mark II* 炮座与炮塔称重、旋转装甲独立质量及炮/装甲/炮座/扬弹机构边界 | 主炮系统分项和旋转装甲拆分 | 作为已有炮座质量的非叠加子项；不能再加入全舰重量 |
| 2 | 机械设备干重清单，明确锅炉、轮机、冷凝器、轴系和所含水/油/工具 | 机械质量分组及载荷变化 | 替换 45/55 筛选分配，并避免与燃料、水、备品重复 |
| 2 | 有日期的正常/满载燃料、水、食品、人员、弹药数量和定义 | 工况重量、续航、稳性比较 | 建立同一日期的载荷案例，保留原代理案例供对照 |
| 3 | 副炮炮座、鱼雷发射装置和鱼雷装备重量及安装数量 | 武备细分、质量中心与载荷 | 明确每项所有权并给每个账本条目独立来源 |
| 3 | 水密舱壁、门、通风道、破口位置及渗透率依据 | 连通进水和剩余稳性的史实解释 | 用真实拓扑替换代理舱室；保留解析场景作算法验证 |

优先级衡量的是对**Queen Mary 数值可信度**的影响，不代表计算功能尚未完成。仅有现存照片、模型图和装甲草图时，上述条目中未能确定的量继续显示估算或未知；不从照片像素、模型包围盒或公布的排水量倒填。收到新资料时，应先记原始值、单位、日期、来源页和包含边界，再调整生成器、重生成项目并集中跑受影响测试及案例比较。

## 继续开发的判定

在没有新史料的情况下，计算核心下一步应以回归和输入契约收尾为主；新功能只有在定义了输入、方法边界和可复核案例后才进入实现。SPS 页面里的“自然速度”仍缺方法定义，这属于**需求语义缺口**，不是 Queen Mary 素材缺口。当前 191 条清单已有逐条状态；不能据此声称对 SPS 全字段或历史实船完成一比一验证。
