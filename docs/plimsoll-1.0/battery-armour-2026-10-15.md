# 炮座装甲估重与采纳闭环验收（2026-10-15）

已补齐原对照报告 F04 的一个缺口：炮罩/炮塔及炮座筒装甲可由厚度和显式炮位假设估重，进入现有审阅、采纳、重算和保存重开流程。先前只有手工质量或声明厚度，本轮可以看到厚度改变引起的质量变化。改动仅在本地，未暂存、提交或部署。

## 如何使用

重量与载荷 → 概念设计 → 对应炮组 →「估算炮罩与炮座筒装甲」。选择独立的所属系统和重量条目，填写正面/防盾、侧面/顶部平均厚度、炮座筒/甲板下厚度；需要炮座筒计算时再声明炮位加权甲板干舷和高度系数。按当前显示单位输入，工程厚度保存为 mm、干舷保存为 m；切换米/英尺只改变显示。空白保持未知，0 明确表示零；不自动填写位置或采纳重量。

若既有手工炮座质量已含同一装甲，需要先明确拆分；本轮不自动扣除。完整装甲角色为 `gun_mount_armour`，其中炮座筒是固定结构；旧 `rotating_armour` 保留，两者在源算法的完整炮组装甲项中各计一次。采纳面板含中英部件名和独立方法版本 `sps-3b3-battery-armour-v1`。
