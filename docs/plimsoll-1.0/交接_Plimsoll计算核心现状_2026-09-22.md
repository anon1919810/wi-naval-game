## 4. 核心接口与硬约定

- `analysis.compute_project(project, condition_id, options=None, *, cancel_check=None)`：统一结果 `plimsoll-analysis-1`，所有阶段在 `result.stages`，原生结果在阶段 `data`。
- `analysis.apply_mass_proposal(..., current_request=...)`：重算身份和模型，接受后只改选定工况；不能仅比较客户端回传的两个指纹。
- `project_store.load/save`：项目 JSON 与计算结果 JSON 是两种不同文件。
- `geometry_import.import_geometry_content(...)`：显式导入字节内容。计算不会自动读取未知的 offsets 引用或生成替代船型。
- `exports.serialize_report/write_report`：已计算结果的 JSON/CSV；`serialize_document/write_document` 用于批量/扫描汇总。不能在导出时再计算一次。
- 开口定义 `unknown`、`supplied`、`legacy_ambiguous` 必须跨保存重开保留。明确无开口是 `supplied + []`；未知不能静默变成空清单。
- 炮座/炮塔装甲/弹药边界不可重复计重；资料不足保持未知或具来源的估算。
- 计算完成、收敛、方法适用、史实验证是不同字段。警告要保留阶段与路径，不能只按相同文字去重。
- Taylor 固定表必须匹配声明的表 ID 与原始字节 SHA256；不能更改表格系数、拟合历史功率或用 caller cwd 查找替代数据。
