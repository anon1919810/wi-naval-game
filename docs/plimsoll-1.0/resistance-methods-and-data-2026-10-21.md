# 阻力计算方法与数据计算报告

生成：2026-10-21 ｜ 分支 feature/plimsoll-1.0 ｜ 对应提交见文末

本报告汇总 plimsoll 现阶段"算功率"的全部计算链、公式、数据来源与实测结果，并把审查中发现的
口径缺陷一并写清楚 —— 因为在这套体系里，**口径错误比模型误差大**。

---

## 0. 摘要

- 同一批 146 条历史案例：原程序口径 MAPE **15.93 %**，Holtrop **12.94 %**，按船型混合 **11.86 %**，
  混合 + 按舰种因子（嵌套留一法）**10.62 %**。
- 五条带出处的试航对照：Dreadnought **+9.27 %**、Bismarck **−0.43 %**、Repulse **+20.06 %**、
  Renown **+25.92 %**、Hood **+22.45 %**（n=5，MAPE 18.19 % → 修正载况后重算见 §7.3）。
- 三个"口径级"发现，都比模型改进更值钱：
  1. 长度基准 LOA→LBP 让 Hood 的误差从 +24.73 % 变 +35.27 %（**10 个百分点**）；
  2. 载况混用（deep 排水配试航功率）让 Hood 从 +35.27 % 回到 +22.45 %（**13 个百分点**）；
  3. 146 条参考集**混用设计额定值与试航值**，Dreadnought 一条就差 3.7 个百分点。

## 1. 单位与符号

**约定**：一切计算走 SI；原始出处的数值保留原单位与出处；只在边界换算一次。
数据集里逐条记录 length_basis（lbp/loa）与载况说明。

| 符号 | 含义 | 单位 |
|---|---|---|
| L_BP / L_OA | 垂线间长 / 全长 | m |
| B | 型宽 | m |
| T | 吃水 | m |
| ∇ | 排水体积 = Δ/1.025 | m³ |
| Δ | 排水量 | t |
| Cb, Cp, Cm, Cwp | 方形、棱形、中横剖面、水线面系数 | – |
| S | 湿表面积 | m²（老口径为 ft²） |
| V | 航速 | kn；Vs = 0.514444·V m/s |
| Fr | 弗劳德数 = Vs/√(gL) | – |
| Re | 雷诺数 = VsL/ν，ν = 1.19e-6 m²/s | – |
| R_T | 总阻力 | kN |
| P_E | 有效功率 = R_T·Vs | kW |
| QPC | 准推进系数 | – |

## 2. 计算链 A：原程序口径（SpringSharp 血统，经验回归）

实现于 tools/plimsoll/concept_estimates.py，逐行对应原 C# 的 HullControl / EngineControl。
**内部是英制**（ft、长吨、ft²），这是它的历史包袱，不是我们的选择。

1. 船型系数
   co = 0.4 × (6B/L)^(1/3) × √(Cb / 0.52)

2. 有效长度（按艉型分支，STERN_TYPES 的索引）
   - 巡洋艉（index 2）：L_eff = B/co + L
   - 小型方尾（index 1）：L_eff = 0.5B/co + L
   - 其余：L_eff = L

3. 湿表面积
   S = 1.7·L·T + 35.0·Δ/T  （单位 ft²，Δ 为长吨；35.0 是海水每长吨立方英尺数）

4. 功率长度（分段，注意 V≤15 时取 2L − L_eff）
   - V ≤ 15 kn：L_hp = 2L − L_eff
   - V ≥ 25 kn：L_hp = L_eff
   - 其他：L_hp = (L_eff − L)·(V − 20)/5 + L

5. 轴马力
   P = [ Δ^(2/3)/L_hp · co · V⁴  +  0.01·S·V^1.83 ] · V / 184.1666667
   - 第一项为兴波项（与 V⁴ 成正比）
   - 第二项为摩擦项（与 V^1.83 成正比）
   - 184.1667 是原程序的单位换算常数（lb·ft/s → hp）
   - 年份修正：engine_year < 1890 时 ×(1 + (1890 − year)/100)

6. 分项（用于报告摩擦/兴波占比，兴波用 L 而非 L_hp）
   R_friction ∝ 0.01·S·V^1.83 ；R_wave ∝ Δ^(2/3)/L · co · V⁴

**特性**：纯经验，无 Fr 域限制、无 Cb 上限、无 Cp 依赖。所以在 32 kn 的细长战巡上会系统性高估
（§7.3 里三艘英战巡 +20~26 % 就是这条链给出的）。

## 3. 计算链 B：Taylor-Gertler 严格源轴

实现于 tools/plimsoll/resistance.py（speed_power_curve），**纯 SI**。

1. 摩擦（默认 ITTC-57，可选 Schoenherr 隐式）
   Cf = 0.075 / (log10 Re − 2)²
   Rf = ½ ρ S Vs² Cf ，ρ = 1025 kg/m³

2. 剩余阻力（源表插值，索引为 Cp × B/T，按体积比修正）
   Rr = Cr(Cp, B/T, ∇/L³) · ½ ρ S Vs²

3. 严格模式（taylor_gertler_source_axis_strict）
   - 四个插值角点的权重必须齐全，**缺角直接拒绝**，不做重归一（诊断 taylor.speed_unavailable）
   - 域：Fr 0.16–0.58；表外端点截断并告警，不外推

4. 功率
   R_T = Rf + Rr ；P_E = R_T·Vs ；轴功率 = P_E / QPC

## 4. 计算链 C：Holtrop-Mennen 1982

实现于 tools/plimsoll/holtrop.py，SI。**与本仓库无关的独立 Rust 实现在同船同系数下核对过**（§8.1）。

1. 湿表面积（回归式，可直接用几何积分面积覆盖）
   S = L(2T + B)√Cm · (0.453 + 0.4425Cb − 0.2862Cm − 0.003467·B/T + 0.3696Cwp) + 2.38·A_b/Cb

2. 形状因子
   L_r = (1 − Cp + 0.06·Cp·lcb/(4Cp − 1))·L
   1 + k₁ = c13 · [0.93 + c12·(B/L_r)^0.92497 · (0.95 − Cp)^(−0.521448) · (1 − Cp + 0.0225·lcb)^0.6906]
   （c12 由 T/L 分段给出；c13 由艉型系数 c_stern 给出）

3. 摩擦
   Rf = ½ ρ S Vs² Cf ，Cf 同 ITTC-57

4. 兴波
   R_w = c1·c2·c5·∇·ρ·g·exp[ m1·Fr^(−0.9) + m4·cos(λ·Fr^(−2)) ]
   c1 = 2223105 · c7^3.78613 · (T/B)^1.07961 · (90 − i_E)^(−1.37565)
   i_E = 1 + 89·exp{ −(L/B)^0.80856 · (1 − Cwp)^0.30484 · (1 − Cp − 0.0225lcb)^0.6367 · (L_r/B)^0.34574 · (100∇/L³)^0.16302 }
   c7：B/L < 0.11 时 0.229577·(B/L)^(1/3)；B/L > 0.25 时 0.5 − 0.0625·L/B；其余取 B/L

5. 其他项
   R_app（附体，按面积×Cf）、R_b（球鼻）、R_tr（方尾）、R_bto（艏推）、R_a（相关补贴，默认 0.04 系数或粗糙度增量）

6. 总阻力
   R_T = Rf·(1 + k₁) + R_app + R_w + R_b + R_tr + R_a + R_bto

## 5. 混合规则（第 3 步成果）

按**船型**而非航速给权重，因此沿功率曲线不会跳变：

    w_H = 1 / (1 + exp((Cb − 0.50) / 0.035))
    R_T = (1 − w_H)·R_T,TG + w_H·R_T,H

- Cb 0.44（驱逐舰量级）→ w_H ≈ 0.85；Cb 0.56（战列舰量级）→ w_H ≈ 0.15
- 只有一侧有结果时：取该侧，标 blended=false 并写明原因，**不冒充两模型一致**
- 连续性：0.001 的 Cb 步长下权重变化 < 0.02（有专门用例）
- 拟合版（可选，不设为默认）：z = −20(Cb − 0.5) − (B/T − 3) + 1；嵌套 LOOCV 11.51 % 对默认规则 11.86 %，
  只值 0.35 个百分点，故保留为选项

## 6. 校准因子（第 4 步成果）

定义（比值总和，而非平均比值）：

    k_type = Σ ref / Σ pred

应用：P_cal = k_type · P；结果行附带 factor / sample / LOOCV / 出处，未覆盖的舰种**直接拒绝**。

| 口径 | 战列舰 | 航母 | 巡洋舰 | 驱逐舰 |
|---|---|---|---|---|
| 原程序 | 0.923 | 0.970 | 1.020 | 0.816 |
| 混合后 | 0.924 | 0.963 | 1.056 | 0.979 |

嵌套留一法（每条船的因子用其余 n−1 条重拟合）：原程序 15.93 % → **12.11 %**；混合 11.86 % → **10.62 %**。

## 8. 审查结论（对现有代码与数据的独立复核）

1. **算术一致**：用独立脚本重算五条案例，co、L_eff、S、P、误差逐条与数据集吻合（差 < 0.05 点）。
2. **载况混用已修**：Hood 原用 deep 排水 47,429 t 配试航功率，改为试航排水 42,200 t，误差 35.27 % → **22.45 %**。
   数据集新增 condition_note 与 sensitivity_pct 字段，把这种混用记录在案而不是藏起来。
3. **长度基准已记录**：全部改用 LBP，并在文件里写明 length_basis；LOA 会让 Hood 少算 10 个百分点。
4. **抓取管线只能给设计值**：36 条里按"句子里自称试航"的闸门自动通过仅 3 条，其余需人工核读。
5. **剩余近似**：Cm/Cwp 在 Holtrop 侧仍用 0.95 与 (1+2Cb)/3；146 案例的 QPC 仍是一个全局 0.440。

## 9. 有了数据之后：还要不要再做修正因子？

分三步判断，不要一上来就拟合。

**第一步：看误差的形状，而不是均值。**
现在 5 条试航里，Bismarck −0.43 %，三艘英战巡 +20~26 %。误差不是均匀散布，而是**跟着船型走**。
若 20–30 条数据仍是这个形状，那么"一个全局因子"就是在平均掉一个本该分段的偏差 —— 这正是第 3 步混合规则要解决的。

**第二步：先分段，再看残差。**
按 (Cb, Fr) 把船分组，比较组内残差的均值与离散：
- 若各组残差均值显著不为零且方向一致 → 该组需要一个**分段常数**；
- 若组内离散远大于均值偏移 → 再校准也压不下去，问题在模型形式（该换方法或补物理项）。

**第三步：要因子就做成分段的，并只做"最后的一致性校正"。**
判据：分段后残差均值的绝对值 < 组内标准差的一半时，不再上因子（否则是拟合噪声）。
一律用**嵌套留一法**评分，并同时报中位数与区间，不能只报 MAPE 单点。

**结论**：**先分段、后因子**。混合规则已经在做"按船型选方法"这件事，因子只应处理剩下的常数偏差，
而且必须是分段的、带样本量的、可拒绝的（现在的 resistance_calibration 就是这个形态）。

## 11. 已知缺陷与未完成

1. 试航样本 **n=5**，且四艘是英国船、集中在 30–33 kn 段，不足以支撑按舰种 LOOCV；
2. 载况记录不全：Hood 的吃水仍是 deep 值，Repulse/Renown 的试航排水未核；
3. Holtrop 侧 Cm/Cwp 用近似式，未用几何或声明值；
4. 146 案例的 QPC 是全局 0.440，把阻力误差与推进误差混在一起；
5. 146 条参考集未按"设计/试航/未知"清理 —— 所有百分比目前只能叫"相对参考的误差"。

## 12. 试航数据集扩建（第 2 轮：从 5 条到 9 条）

按"两端取样"扩表：慢速战列舰补了 3 条（Orion 21.3 kn、Monarch 21.9 kn、Ise 23.6 kn），另加扶桑 23.0 kn。

### 读数结论（每条都是逐句读出来的，不是正则直接落盘）

| 舰 | 原文 | 判定 |
|---|---|---|
| HMS Tiger | "designed to produce 85,000 shp … but only **achieved 104,635**" | ❌ 机器抓的是设计值，未收 |
| HMS Lion | "designed to produce 70,000 shp, but achieved more than 76,000 during her trials" | ❌ 设计值，未收 |
| HMS Revenge | "rated at 40,000 shp and **intended** to reach 23 kn" | ❌ 设计值，未收 |
| HMS New Zealand | "produced **over** 49,000 shp" | ⚠️ 下界 + 只有 LOA，暂缓 |
| HMS Barham | 1933 年改装后测速 22.5 kn / 65,655 shp | ⚠️ 条件特殊，存疑未收 |
| **扶桑** | "exceeded her design speed of 22.5 kn …, reaching **23 kn at 46,500 shp**" | ✅ 收（注意配对是 23 而非 22.5） |
| **Orion / Monarch / Ise** | "reached a maximum speed of 21.3 kn from 30,552 shp" 等 | ✅ 收 |

### 结果（n=9）

| 口径 | MAPE | 中位 | 区间 |
|---|---|---|---|
| 全部 | **10.89 %** | 9.27 % | −10.94 % … +25.92 % |
| 战列巡洋舰（3） | 22.81 % | 22.45 % | +20.06 % … +25.92 % |
| 战列舰（6） | 4.92 % | 4.08 % | −10.94 % … +9.27 % |
| ≥30 kn（4） | 17.21 % | 21.25 % | −0.43 % … +25.92 % |
| <24 kn（5） | **5.82 %** | 5.46 % | −10.94 % … +9.27 % |

### 最重要的新发现：误差在两端**变号**

- 31.7 kn 以上的战巡：**全部高估 +20 … +26 %**；
- 21.3–23.6 kn 的慢速战列舰：**全部低估 −0.8 … −10.9 %**（Dreadnought 的 +9.27 % 是唯一例外，
  且它是这批里唯一用 deep 吃水配正常排水的条目）。

也就是说，误差不是"整体偏大"或"整体偏小"，而是**随航速/细长度改变符号**。
这直接说明：任何全局常数因子（包括 0.924）都是在平均一个**穿过零点**的结构，
它的数值会随样本里快慢船的比例漂移 —— 这是"先分段、后因子"最硬的实测依据，比之前 146 条案例的间接证据更直接。

### 记录方式

- 三条新数据都只有**全长**（页面未给垂线间长），已在 `hull.length_note` 里写明"约 2–3 % 偏乐观"；
- Ise 另一条 25.3 kn / 81,050 shp 是**改装后**的试航，未混入；
- 校验器与测试保持 10 例通过，数据集 n=9。
