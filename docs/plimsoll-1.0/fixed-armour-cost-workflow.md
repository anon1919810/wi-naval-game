# 装甲、武备与造价的连续审阅

本页描述 2026-10-16 本地增量的操作约定。已执行的统一验收与保留边界见[本轮记录](coverage-marathon-2026-10-16.md)。

## 从现有工程开始

在「重量与载荷」的概念设计中编辑炮组、两组炮位布局、固定装甲及造价配置。已有工程可以逐项增加这些声明，不需要重新导入。导入 SpringSharp 3.0 文件仍先预览，再保存为新工程；原始字节、备注、尺度和转换依据留在来源归档中。

同一入口还可声明鱼雷、水雷、深水炸弹／反潜迫击炮。每一行绑定已有系统叶节点和独立重量条目，角色为「其他」。建议质量是器材与发射装置的合计，不应同时在另一个条目中重复计入装置重量。

固定装甲每一项绑定已有系统叶节点和一个独立重量条目。主装甲带、端装甲带、上装甲带、防雷舱壁、防雷凸舱、甲板、指挥塔分别使用对应角色。炮罩及炮座筒装甲属于另一个独立目标。若既有炮座重量已经包含装甲，先按自己的资料拆分账本，再选择独立目标；软件不会自动从旧重量中扣除一部分。

新导入建立的重量条目以未知质量开始。输入了厚度和长度，也不等于已经采纳估重，更不等于已有型线或重心。不能用来源参考排水量填满整份重量表。

## 填写声明

装甲带、防雷舱壁及防雷凸舱填写厚度、长度和高度。主／上装甲带还需要船长、船宽与经验水线面系数；简单平板分量不需要借用干舷、轴数等无关输入。倾角在原程序中用于高度告警，没有被擅自加入重量公式。

甲板填写七种覆盖方式之一、前后甲板长度比例及三段厚度。前后比例相加不能大于 1。机械舱／弹药库箱式覆盖还读取当前工况的机械和弹药质量；未采纳的建议不会成为已存在的机械或弹药。已知为零与没有提供，是两种不同状态。

指挥塔填写前、后两项厚度，由声明排水量得到一个合并估重目标；不会据此生成实际塔体尺寸或重心。所有厚度规范保存为毫米，长度保存为米；显示偏好可以换成英尺，保存和导出仍保留规范数值。

鱼雷填写装载总数、组数、直径、长度和九种布置之一。组数不乘入重量；未知组数可以保留。水雷和深弹的另一项计数是备弹数，会加到装载数中；单件质量指整个器材，不是炸药量。水雷、深弹各有四种布置，装置重量系数按恢复表读取。切换鱼雷与另外两类时，组数／备弹数与布置清空待重填；水雷与深弹互换保留单件质量和备弹数，重新选择布置。

「装甲长度与高度审阅」单独启用，填写假设来源和正负倾角。主、端装甲带采用同一声明倾角；上装甲带、凸舱和舱壁有各自高度规则。主带标准长度比以船长的 65% 为分母。机舱／弹药库的经验最小主带长度，只有当前空间比与综合强度至少 0.5 可读时才显示。缺项或主／端带不唯一时保持不可用。告警用于审阅，不阻止质量采纳，也不自动修改几何；倾角改变高度门限，不改变估重。

## 分三次审阅

1. **先看部件。** 保存修订并运行，核对火炮、弹药、炮位装甲和固定装甲的来源、独立目标、估重及差值。勾选需要采纳的项，再应用并重算。没有选中的项目保持原值。
2. **再看相互影响。** 装甲改变后，轮机的经验需求可能改变。重算只产生新的建议，仍须再次审阅、勾选。造价读取当前已采纳的机械、弹药、燃料及火炮承载项；只采纳装甲不会直接改写这些输入，也不会自动改变造价。
3. **最后看结构和平衡。** 在当前已选工况中看新的结构需求、现有结构、目标排水量和差额，再决定是否采纳结构建议。经验强度达标不会自动补齐重量差额。

每次采纳只写当前工况的覆盖和来源凭据，基本账本与其他工况保留。再改厚度、炮位或目标排水量时，先前已采纳的质量仍是当前质量，直到下一次明确采纳。既有比较容差内可能没有新建议；这不表示编辑被忽略。

草稿、计算选项或工况改变后，先前建议不能继续当作当前建议。采纳保存成功而后续排队失败时，页面说明已保存的修订并允许重试计算，不把已经保存的采纳描述成回滚。

## 读取造价与报告

造价是单独启用的读数，没有可以采纳到重量账本的“造价质量”。显示原 SPS 的百万英镑／百万美元约定及固定 4:1 比值；年份调整也沿用原式。它可用于同口径方案比较，不提供现代汇率或市场报价。

完整报告读取保存结果中的炮位、装甲、辅助武器、尺寸审阅及造价分量，带上方法版本与来源。跨修订对照按记录 ID 对齐，而不按数组顺序猜测。子分量不可用、ID 重复、方法身份缺失或方法不一致时，不给出伪精确的差值。完整报告继续保留请求状态与完成状态门限；失败或未完成阶段的残留数字不会被当成报告结果。工作台允许独立可用部件继续审阅，因此导入后缺少平衡声明时，两处展示范围可能不同。

JSON 和 CSV 保存的是原结果与规范单位，不会随报告的临时显示偏好被改写。网页当前工况的读数、另一个保存工况的结果与全船历史真实性，是三件需要分别判断的事。
