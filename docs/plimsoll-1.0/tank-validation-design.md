# 矩形舱液体几何验算设计

日期：2026-09-22。Task 5 实现前的接口与解析验算约定；不是实现通过的声明。

## 坐标、输入与处理方式

`liquid_state(tank, volume_m3, heel_deg=0, trim_deg=0)` 中的 `volume_m3` 是实际液体体积。舱体沿用已有显式几何键：`length_m, beam_m, height_m, x_m, y_m, keel_to_bottom_m, permeability`；前三者为舱体矩形尺寸，x/y 为几何中心，底部高度自龙骨量。不得用未知位置的隐式零代替。

与船体采用同一水面斜率定义：`p=tan(trim)`、`q=tan(heel)`，液面为 `z=p*x+q*y+d`，法向为 `(-p,-q,1)/sqrt(1+p²+q²)`。给定体积反求截距，再以裁剪后的真实体积积分求水体重心。联合倾斜不应静默退化为正浮重心。

对于均匀渗透率代理，水体体积是裁剪几何体积乘 μ；因此反求的几何占据体积为 `Vwater/μ`。μ 不再次改变灌注高度。均匀 μ 是分布假设，不是已测得的真实设备空隙。μ=0 时只允许零液体体积。

实现可使用凸多面体半空间裁剪加四面体体积/一阶矩积分；在舱体局部坐标积分可减少远离原点时的相消误差。沿任意剖面数值积分也可，但必须通过解析与细化验证。所有形状与物理输入严格拒绝布尔数值、NaN/Inf 和超舱容。

## 输出含义

- 几何体积、可渗入舱容、实际水量、填充比例；非零水量的船体坐标重心。
- 自由液面截面的顶点、面积、平面内正交基及关于截面形心的面积二阶矩。输出必须说明惯性矩是几何值还是含均匀 μ 的可用面积值。
- 空舱重心为 null（无液体），不是任意零点；空舱/满舱自由液面关闭，满舱重心是几何中心。
- 计算方法、假设、支持角域、适用性和诊断。不要用几何重心移动的精确效应再叠加同一水体的经验 FSC。
- 如保留旧 `free_surface=false` 行为，应明确表示“锁定重心的固态载荷近似”；部分装液的密闭舱并不因关闭阀门就消除自由液面。

## 固定解析锚点

取 `L=10 m, B=4 m, H=4 m, x=y=z_bottom=0, μ=1`，半舱实际水量 80 m³。

正浮：重心 `(0,0,1)` m；水面面积 40 m²；绕纵轴的面积惯性矩 `L*B³/12=160/3 m⁴`，绕横轴 `B*L³/12=1000/3 m⁴`。

取 `p=0, q=1/2`（横倾角 `atan(1/2)`），水深在左右端为 1 m 与 3 m，未切底/顶，故：

```
y_water = q*B²/(12*T) = 1/3 m
z_water = T/2 + q²*B²/(24*T) = 13/12 m
x_water = 0
```

这里 `T=2 m` 为平均水深。将 q 变号，只有横向重心变号。对任意整体平移，体积和面积矩不变，重心随平移移动。

均匀 μ=0.4 时，同样半舱对应实际水量 32 m³，而重心仍相同。若将几何面积惯性矩用于小角自由液面质量矩，与实际重心导数一致的可用面积因子应声明为 μ；不要混用旧接口仅对舱容减 μ 而对自由液面不减 μ 的另一套假设。集成时明确比较/迁移，旧测试不能冒充新模型的依据。

联合斜率且水面不切底/顶时，另一个独立锚点是：

```
x_water = p*L²/(12*T)
y_water = q*B²/(12*T)
z_water = T/2 + (p²*L² + q²*B²)/(24*T)
```

## 验收

解析体积/重心用相对 `1e-10`、近零绝对 `1e-10` 验证；若使用迭代求截距，先固定其体积公差再对输出判断。顶/底被切的三角楔另作分段积分验算，不能只测平面均未穿边的情况。

必须覆盖：零水量、满舱、μ=0、超容量、左右镜像、联合倾斜、平移、极小非零体积、显式关闭自由液面代理、面积矩和体积/一阶矩守恒。极端倾角超实现域时明确拒绝。
