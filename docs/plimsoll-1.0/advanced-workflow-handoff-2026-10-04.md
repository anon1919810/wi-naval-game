存储层新增可选根字段 `flooding_scenarios`，由 `tools/plimsoll/project_extensions.py` 做轻量结构、引用、数值域与元数据校验，不执行计算。草稿可含未知值；运行时仍校验完整性。旧项目缺此字段保持原义。基础舱室 ID 须非空且唯一，表单不任意改名；被主带研究或破损预设引用时阻止删除。仍使用 15 阶段协调器。

质量账本是唯一质量权威。物理公式不生成重复质量；场景液体是账本外附加质量，不把原有压载水再次计入。原始项目、API 请求、结果 JSON 和 CSV 继续使用规范单位与原字段名。来源、三态估算、未知与已知零保留。

## 使用

详细步骤见[高级输入与破损操作说明](advanced-input-workflow.md)。先保存修订，再选择场景和请求参数运行；请求草稿不跨重开保存。淡水研究需显式填写统一环境密度。参与开启连接的场景舱室须声明存在自由液面。

单位偏好在船型页保存。字段值按当前显示单位解释，再换回字段自身规范单位；例如 1 ft² 保存为 0.09290304 m²，0.6 t 弹丸输入保存为 600 kg。偏好切换不改原始数值、不填未知、不改来源或估算状态。报告可临时切换单位，避免为了阅读已有结果而再运行计算。

结果属于其保存的修订、工况、场景和请求指纹。改变当前请求不会重算旧结果；工作台标明结果身份。短于请求时长的轨迹必须结合停止原因解释，部分结果不能当成完整或安全结论。
