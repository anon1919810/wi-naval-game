# 平衡态小扰动横向稳性：方法设计

状态：2026-10-15，按已批准的 F06 范围实施；不是完整动态横摇或实船安全验算。

## 问题与范围

当前 `gm_t_m` 定义为直立几何 KM 减选中 KG，纵倾非零时按定义不可用。不能删除这个限制，或直接把现有 `stability_curve.initial_stiffness_m` 改名为 GM：后者对水面斜率角求导，斜率角在有纵倾时不等于物理横摇角。

本轮增加零横倾平衡态附近、允许升沉与纵倾重新平衡的横向恢复力臂导数。支持有纵倾的闭合截面几何，以及现有求解器支持的移动液体质心。非零平衡横倾、几何接触/饱和、边界超出、失去平衡或未达到数值细化标准时返回有理由的不可用结果。旧直立 KM/GM、GZ 斜率角定义和经验设计评分保持各自身份。

接触检查应使用与船体尺度及浮点舍入相称的坐标容差：平衡求解通常不会使数学上的接触恰好得到浮点零值，不能只依赖现有几何适配器的精确 `== 0` 边缘标记。该容差用于拒绝接触附近不可分辨的导数，不能放宽平衡残差或伪造几何精度。

## 接口与定义

新模块 `tools/plimsoll/small_angle_stability.py`，公开函数：
`analyze(hull, loading_state, options=None, *, step_deg=0.2) -> dict`。

方法版本 `free_trim_equilibrium_roll_stiffness_v1`。`options` 使用现有平衡求解器的密度、角度范围、液体及初值；不增加项目/网络请求选项。`step_deg` 为有限非布尔数，0.02..0.5 度，控制三组对称水面斜率角扰动 h、h/2、h/4。

函数自行从原始几何、选中载荷和选项求得基态，不相信外部传入的序列化平衡结果。一次准备几何，复用现有平衡求解引擎；不创建第二套几何或液体积分器。共享已有私有求解器作为包内实现细节可以接受，但须明确记录耦合，不扩展公共“任意已准备对象”接口。

基态横倾绝对值不超过 1e-7 度；质量和三轴重心完整，自由平衡收敛且横向残差通过，水面处于有效部分浸没状态。若 options 提供非 null 的 `heel_deg`，明确返回不可用，不能把强制直立误认为自由横向平衡。基态固定单位轴为 u0（纵向）、v0（横向）、n0（水面法线）。每次扰动固定斜率横倾角，升沉与纵倾自由求解，并重新求液体质心。

对每个扰动结果，用其单位水面法线 n 和当前浮心 B、实际有效重心 G 计算：

- 物理横向角 `phi = atan2(-dot(n, v0), dot(n, n0))`，单位 rad；
- 恢复力臂 `R = dot(cross(B - G, n), u0)`，单位 m；
- 在基态 phi=0 处用正负实际 phi 的非等距中心三点差分求 dR/dphi。保留基态残余力臂，不能假定数值上恰为零。

三组差分中取最细组。细/中组差不超过 `max(1e-5 * base_beam_m, 0.002 * max(abs(fine), abs(medium)))` 才标记数值细化通过；这只是扰动细化检查，不是几何离散收敛或实船误差证明。符号分辨阈值为 `max(refinement_delta_m, 1e-6 * base_beam_m)`。负恢复导数作为已求得的失稳方向保留；绝对值落在符号分辨阈值内则标记未分辨，不能拿来计算横摇周期。

结果至少包含：`status`、`reason`、`method_version`、`definition`、`equilibrium_gm_m`（不可用为 null）、`restoring_sign`、`refinement_delta_m`、`sign_resolution_m`、`base_equilibrium`（受控精简字段）、三组样本及其实际角/力臂/平衡残差、`validity`、`diagnostics`、`fsc_policy` 和输入指纹。所有数值必须有限、可严格 JSON 序列化。历史验证和安全结论保持未知。

## 独立解析校核

连续直壁矩形箱体 L×B、平均吃水 d，水面 z=d+p*x，所有截面均未触底/顶。可独立积分得：
`V=L*B*d`，`xB=p*L²/(12*d)`，`zB=d/2+p²*L²/(24*d)`。
令重心高 zG，选取 `xG=xB+p*(zB-zG)` 使连续船体在该纵倾平衡，则对称箱体的自由纵倾横向恢复高度为：
`sqrt(1+p²) * (B²/(12*d) + zB - zG)`。

基准参数 L=20 m、B=8 m、d=4 m、箱深12 m、zG=2.8 m，纵倾0/5/15度。使用至少129站，对连续解析值相对误差要求2e-4、绝对误差2e-5 m；另用更细站数核对几何误差缩小。15度用例会识别把斜率角直接当物理横摇角的错误（规划探针约0.83245 对0.86181 m，连续解约0.86185 m）。解析公式是本设计针对上述箱体的独立推导，不能推广到任意船体。

还须验证：正负纵倾/横向镜像、竖向基准平移、几何及载荷尺度变换、负刚度/近中性、未知载荷/未知重心、触底触顶、扰动越界/不收敛、拒绝非法步长、移动液体与解析自由液面修正一致且不双算。不得用被测函数输出构造期望值。

增加自由纵倾约束的独立反例：将上述箱体每站横向中心改为 y=k*x，k=0.2，CG=(0,0,2.8)，仍保持 L=20、B=8、d=4、深12、质量656 t、rho=1.025。设 A=L²/(12*d)、J=B²/(12*d)、D=d/2-zG，则一阶纵倾平衡为 `(A+D)*p+k*A*q=0`，自由纵倾恢复高度为 `J+k²*A+D-(k*A)²/(A+D)`，解析值0.49793510324483814 m；固定纵倾值0.8666666666666671 m。另核对 dp/dq=-k*A/(A+D)。129和257站的几何误差应缩小，此反例能识别误把纵倾锁住的实现。该非对称模型的周期必须不可用。局部某站的顶边/底边与水面接触，即使整体仍部分浸没，也须被接触门限拒绝。

## 集成与横摇

`hydrostatics.data.small_angle_stability` 保存新结果，`values.equilibrium_gm_t_m` 提供同一个数值；旧 `values.gm_t_m` 的含义和不可用状态不变。阶段及请求的方法身份须包含新方法版本，防止旧结果冒充当前结果。

原直立且无移动液体的横摇路径可保留原结果。零纵倾、零横倾且有非零移动液体时，仅当新结果数值通过且恢复符号明确为正，才允许用新恢复高度计算小振幅横摇。仍需有来源的显式回转系数和有效横向尺度；不填默认系数。新路径须带新的方法身份 `selected_loading_equilibrium_roll_v2` 和恢复高度来源，并说明忽略附加惯性/阻尼、不是完整动态求解。移动液体通过每个姿态的质心重算，禁止再叠加一次 FSC。

有纵倾时，u0 与现有 `roll_gyration_coeff` 所代表的船体 x 轴不同，不能把现有 k_xx/B 当作绕 u0 的惯性。本轮只输出平衡态恢复高度，横摇周期仍为不可用，原因明确包含惯性轴资料缺失；即使旧系数有来源也不能绕过。新惯性张量/轴元数据及完整耦合动力学不在本轮范围。新恢复高度是升沉、纵倾静态重新平衡后的导数，不能单凭静态消元声称已得到耦合系统固有周期。

任意非对称模型在直立时也可能有横摇/纵摇耦合。横摇周期还必须证明所建模型关于 y=0 镜像对称：每站闭合多边形经 y→−y 反射后相同（不依赖顶点起点或方向），每个正质量固定载荷条目的 y=0，每个非零移动矩形舱的横向中心为0。只验证总 TCG=0 不够；本轮保守地不支持靠离轴成对重量或成对舱来证明对称。未知或证明失败时恢复高度仍可用，周期返回缺少解耦依据。这个对称条件使升沉、纵倾关于横倾为偶函数，因此一阶响应为零；不能用依赖坐标原点的原始截距导数冒充该证明。原直立无液体周期的公式、方法身份及已满足条件的结果保持原状，新的对称门限也用于防止旧路径绕过耦合限制。

网页与报告分别显示直立几何 GM、平衡态等效 GM 和横摇缺项原因，补全单位与中英标签。不把新值换进旧字段。Queen Mary 两个工况必须重新计算；有来源的回转系数缺失时横摇继续不可用，阻力仍保持原有适用性限制。
