## 结论边界

用户确认“SOS”为笔误，比较对象为 SPS / SpringSharp。旧覆盖表引用七页截图和 SpringSharp3b3。尚无完整、可复核的同输入逐项对照，因此不宣称全面替代或全面超越。

1.0 聚焦完整设计分析流程、可解释计算与简化破损剖视。完整耐波性、有限元/结构强度、历史造价及海战命中/穿透系统不在批准范围内。它们不能被空字段、经验占位或更好的界面冒充实现。

Queen Mary 数据里仍有重大估算：型线来自模型；吨位原始单位和试航载荷不完全明确；重量位置缺少实测来源；模型包围盒面积不等于装甲真实展开面积。数值算法通过验证不代表这些输入已经史实验证。
