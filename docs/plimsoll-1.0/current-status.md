## 本轮新增计算接口

- `analysis.compute_project` 维持 15 个阶段；请求指纹覆盖目标纵倾、阻力模式与固定轴功率。
- 主副炮、鱼雷等行按所选载荷账本投影，炮弹齐射质量独立计算；装甲按声明行分组，关键舱段覆盖长度另作有来源的估算研究。
- 甲板干舷与所选载荷横摇周期保留输入缺失时的 `unavailable`；动力页区分安装机械质量和可变载荷分组。
- 后续有界增量加入装甲甲板平面覆盖率：只有受保护面积和参考面积均有来源时才给百分比，缺值为未知，不改变重量账本。Queen Mary 暂无可审查的两项面积，故不填历史数值。
- 炮塔旋转装甲可作为有来源的主炮座质量子项单列；所选炮座质量不足时返回不可用与诊断，不增加全舰或固定装甲质量。Queen Mary 没有独立来源，仍为未知。
- Python API、单工况/批量/扫描 CLI、JSON/CSV 导出已实现；191 条观察记录有逐条状态和限制。
- 两个增量合并后全量回归通过 700 项、0 失败；此前 691 项是增量前基线。10 秒通用二舱场景三次测量中位数 4.035 秒。60 秒连通进水压力测量因用户要求聚焦类 SPS 核心而不作本轮闸门。
- 装甲甲板覆盖率增量通过相关路径 97 项针对性测试；炮塔旋转装甲拆分增量通过相关路径 116 项针对性测试。Windows 中文子进程测试另修复了 UTF-8 输出约定；修复前全量回归 700 项中有 2 处测试运行器解码错误，修复后的同一套测试全部通过。

## 数据与方法边界

Queen Mary 工程账本正常质量为 27,851.62934079477 t，满载质量为 31,926.26200617077 t；位数用于计算复现，不代表历史精度。型线来自模型，重量位置、装甲面积和部分来源单位仍含估算。模型包围盒面积不等于真实装甲展开面积；没有用任意补差重量制造吨位吻合。

[Queen Mary 输入资料准备度](queen-mary-input-readiness.md)按结果影响列出了当前史料缺口及补证顺序。未获来源的装甲甲板平面覆盖率、旋转炮塔装甲独立质量和关键舱段史实范围继续显示未知或仅限代理研究。

原有数值验证包括独立方箱/椭球基准、倾斜液体守恒、进水步长收敛和外部阻力公式基准。数值正确性不能替代输入史实验证，也不能证明全面超越 SPS。完整耐波性、结构强度、历史造价和海战穿透/爆炸求解仍在批准范围外。
