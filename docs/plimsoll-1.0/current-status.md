## 数据与方法边界

Queen Mary 工程账本正常质量为 27,851.62934079477 t，满载质量为 31,926.26200617077 t；位数用于计算复现，不代表历史精度。型线来自模型，重量位置、装甲面积和部分来源单位仍含估算。模型包围盒面积不等于真实装甲展开面积；没有用任意补差重量制造吨位吻合。

原有数值验证包括独立方箱/椭球基准、倾斜液体守恒、进水步长收敛和外部阻力公式基准。数值正确性不能替代输入史实验证，也不能证明全面超越 SPS。完整耐波性、结构强度、历史造价和海战穿透/爆炸求解仍在批准范围外。

服务器信息作为后续部署条件保留，本轮未连接或部署服务器。[官方便携运行库准备](runtime-release-candidate.md)保留为后续资料，不继续作为计算核心的阻塞项。
