# 倾斜平衡验算设计（实现前固定）

日期：2026-09-22。供 Task 4–6 实现和独立复核使用；本文是解析验算设计，不是测试已经通过的声明。

## 现有接口的适用边界

`geometry.StationedHull.integrate(phi_rad,d,trim_rad)` 用水面 `z=p*x+q*y+d` 裁剪，其中 `p=tan(trim_rad)`、`q=tan(phi_rad)`。这两个角定义水面斜率；联合倾斜时不能把它们未经变换解释为任意顺序的欧拉角。

旧 `solve_trim_equilibrium` 求 `LCB=LCG`，忽略倾斜后垂向重心差对力矩的投影。它作为旧接口可保留，但不能直接宣称满足新加载状态的完整静力矩平衡。新的 `solve_loaded_equilibrium` 应用下述同一平面法向核验。

## 三个残差

在船体坐标中，水面向上单位法向为 `n=(-p,-q,1)/sqrt(1+p²+q²)`。重量和浮力方向相反，平衡要求 `V=M/rho` 且 `B-G` 平行于 `n`。

故可用以下三个残差求解截距和两斜率：

```
r_volume = V - M/rho
r_longitudinal = (Bx-Gx) + p*(Bz-Gz)
r_transverse   = (By-Gy) + q*(Bz-Gz)
```

`Bz` 和 `Gz` 必须采用同一基准；若几何龙骨坐标为 `kz`，输入 `KG` 必须先转为 `Gz=kz+KG`。方程来自力矩的叉积，不能仅由正 GM 判为平衡或安全。

新结果应给出原始和尺度化残差、收敛状态、求解边界、迭代次数，以及明确的倾角定义。暂不支持的角度/几何应显式失败，而非返回最后迭代作为成功。

## 可独立推导的方箱解析锚点

取封闭直壁方箱，龙骨 `z=0`，纵向和横向范围分别为 `[-L/2,L/2]`、`[-B/2,B/2]`；整个水面均在底板与顶板之间。令 `d=T`，则对水柱高度 `h=T+p*x+q*y` 积分：

```
V  = L*B*T
Bx = p*L²/(12*T)
By = q*B²/(12*T)
Bz = T/2 + (p²*L² + q²*B²)/(24*T)
```

固定 `Gz`，选择 `Gx=Bx+p*(Bz-Gz)`、`Gy=By+q*(Bz-Gz)`，即可在指定水面斜率处构造一个解析平衡输入。它测试真实力矩条件，不把求解器输出反填成期望值。

预定联合倾斜算例：`L=40 m, B=10 m, depth=10 m, T=4 m, rho=1.025 t/m³, Gz=3 m, p=0.01, q=0.1`。四角水深范围 `[3.3,4.7] m`，满足公式条件。由上述解析式直接生成质量和 CG 期望，禁止从生产积分函数取预期值。交换 `q` 的符号并镜像 `Gy`，必须得到镜像响应。

纵向离散采用足够站位；梯形积分对 `x²` 有可计算离散误差，不能把解析式与低站数结果硬要求浮点精度一致。离散加密应逐步收敛到解析锚点；生产求解器的自身残差与对连续解析解的离散误差分别验收。

## 容差和补充验证

- 代数、单位及连续解析构造：相对容差 `1e-10`，近零绝对容差 `1e-10`。
- 求解体积残差按目标体积缩放；纵/横力臂残差分别按 `L`、`B` 缩放，绝对值均不超过 `1e-6`。
- 非方箱站位/截面分辨率加密：选定的体积、浮心和 GZ 指标相邻细化变化小于 `1%`；同时报告实际分辨率和误差，接近零的力臂采用事先声明的绝对尺度。
- 额外测试：龙骨整体平移不改吃水和物理结果；超载、零体积、不有限输入、未括住根必须失败；正采样末点不能替代 AVS。
- 对进水液体使用同一 `n` 与坐标变换，若已显式移动水体重心，不再对同一水体重复施加自由液面虚升高。

该锚点只证明数值与解析一致，不能证明 Queen Mary 的估算型线或 KG 是史实。

## 独立非方箱细化锚点

采用中心为 `(0,0,c)`、半轴 `(a,b,c)=(20,5,5) m` 的椭球，
水面取 `p=.01,q=.1,d=4 m`。通过 `x=aX,y=bY,z=c+cZ` 将其映射为单位球，
令 `S=sqrt((pa)²+(qb)²+c²)`、`t=(d-c)/S`、`F=2+3t-t³`，
对单位球横片积分得到：

```
V = pi*a*b*c*F/3
mu = -3*(1-t²)²/(4F)
B = (-mu*p*a²/S, -mu*q*b²/S, c+mu*c²/S)
```

生产积分器不参与上述期望值。可复算脚本为
[coupled_ellipsoid_oracles.py](evidence/coupled_ellipsoid_oracles.py)：
连续体积 `738.9616567702825 m³`，浮心约 `(0.389924864,0.243703040,2.562969602) m`。
脚本以 `rho=1.025 t/m³,KG=3 m` 构造自由平衡输入，以及指定横倾、
纵向自由、`GZ=.15 m` 的另一个重心输入；两者均不从求解器输出反推。

测试将椭球离散为余弦纵向站位和多边形椭圆剖面，使用至少
`(站数,剖面点数)=(41,32),(81,64),(161,128)` 的细化序列，另分别固定
剖面或站数以区分两个离散来源。检查求解后的体积、浮心、浮态和受约束 GZ
向连续锚点收敛；最终相邻两层体积/浮心/GZ 变化按前述 `1%` 验收。
近零位置或力臂采用预先固定的 `1 m` 绝对比较尺度，角度以目标非零角度
为尺度；每个返回状态还必须单独满足自身尺度化平衡残差 `1e-6`。
这是新增求解器的待验收要求，不把旧积分器的固定水面探针结果算作通过。
