# SpringSharp 3.0 工程迁移本地验收（2026-10-15）

已完成原对照报告 F07 的有界迁移：命令行和网页调用同一解析器，将 SpringSharp 3.0 `.sship` / 同头 `.dat` 转为可编辑的 Plimsoll 草稿。网页先预览，确认后另存新 UUID、修订 1。改动在本地，未暂存、提交或部署。

## 使用与变化

- 网页：项目库 →「选择 SpringSharp 文件」→ 核对来源摘要、迁移限制和字段 →「保存为新项目」。原 JSON 备份入口继续保留。
- CLI：`python -m plimsoll import-sship ship.sship --preview`；去掉 `--preview` 输出规范项目，可加 `--output converted.project.json`。新命令独占创建目标，拒绝已存在目标、源别名和解析期间出现的目标，不覆盖原工程。
- 280 条参数、25 条早期重复字段、33 条填充字段全部留存；原始字节、SHA256、编码、精确备注和转换依据随规范 JSON 备份保存。四类处置合计 280，随输入变化，不能当作 SPS 功能覆盖率。
- 处理逗号/点小数、合法千位分组、UTF-8/BOM、UTF-16 LE/BE、CR/LF/CRLF；弹重始终按磅、五项杂重始终按长吨。装甲长度使用装甲页自身尺度，独立于船体页。
- 混合两组炮座保留各组座数、每座门数及共用炮架含义。源总炮管数与炮座推导不一致、小数计数或不受模型支持的值保留原文并提示，不截断、夹紧或编造模型。
- 建立一个明确标注为生成的工作工况，参考质量为空、覆盖项为空。火炮及燃料估重可独立审阅、采纳；无来源轴功率和必要平衡输入时，机械估重仍不可用。
