# 自动估重与概念设计平衡

在项目库选择「概念巡洋舰」可以直接试用。该项目是一份合成设计；没有对应的真实舰船，也没有型线几何，因此默认计算的整体状态为「部分完成」，概念设计平衡阶段可以单独完成。

1. 在「重量与载荷」开启概念设计，填写声明来源、年代、目标排水量、代表性干舷、艉型和轴数。输入缺失时保留未知状态；声明中的起始布局系数可以修改，并须注明假设来源。
2. 为炮组选择所属系统及三个独立台账条目，填写口径、身管长、炮座类型、数量与弹药。机械和燃料也绑定到所属系统的已有条目。为所有有质量的条目分配角色；空角色集合代表该类质量为零，未分类质量会阻止依赖它的估计。
3. 保存修订，再运行计算。概念设计存在时会自动请求 `design_balance`，旧项目继续使用原来的默认阶段。
4. 在估重建议中查看当前质量、建议质量、差值、方法版本、来源和适用范围，勾选需要采纳的条目。同一条目只能选择一种模型。建议按部件先行、结构随后审查。
5. 点击「应用所选估计并重算」。服务端针对同一保存版本重新计算并核对整批建议，原子保存为一个新修订，再使用相同选项排队计算。重量写入当前工况的覆盖与来源记录。基本重量和其他工况保留。
6. 重算后审查新的结构需求，再决定是否采纳。结构需求由强度系数反解；排水量差额、结构需求、结构余量分别展示。

修改草稿或未应用的 JSON 会隐藏旧建议。改变计算选项后，需要重新计算再审阅。过期、伪造、重复、归属不明、派生工况和空批次均拒绝；其他页面同时保存则返回版本冲突。采纳已经保存而重算排队失败时，页面说明保存的修订并提供重试。切换项目、工况、选项或编辑后到达的旧响应不会覆盖当前草稿或跳转页面。

合成例按上述顺序采纳五项部件，再采纳新结构建议，综合强度约从 0.836 经 0.839 达到 1.000，最终台账为 7616.56 t，声明目标 8200 t，差额仍为 583.44 t。达到经验强度目标不会自动填补重量差额。

方法版本 `sps-3b3-adapted-v1` 采用恢复的 SpringSharp 3b3 数学段，并适配显式台账。支持声明范围内的蒸汽机械；不含造价模型、完整炮位/装甲布局或 `.sship` 迁移。平衡面板的稳性、稳当性和耐波性是经验分数。物理静水力、GM、GZ、纵倾与横摇须另行计算；历史真实性保持未知。质量单位由字段和显示偏好明确标注，原方法的结构质量为长吨、齐射项为磅。

实现与证据范围见 [当前覆盖](concept-design-coverage.md)。
