# 阻力对标第一步：内核等价性与转换口径 · 2026-10-19

目标：判断 plimsoll 的 Holtrop-Mennen 与 ssrcalculator（Rust 重实现，MIT）的 Holtrop 是否等价，
以便决定能否直接借用它的按舰种校准因子（战列舰 0.767 / 航母 0.803 / 巡洋舰 0.919 / 驱逐舰 1.017）。

## 结论

**内核的摩擦侧完全等价；差异来自输入系数与轴马力转换口径，不是算法。**

同一条船（HMS Dreadnought，L 157.417 m / B 24.994 m / T 8.077 m / Cb 0.56 / Cm 0.97 / Cwp 0.75，21 kn）：

| 量 | ssrcalculator 公式 | plimsoll 内核 |
|---|---|---|
| 湿表面积 S（Holtrop 回归） | 4,399.67 m² | 4,399.7 m² |
| 形状因子 1+k | 1.1225 | 1.123 |
| 摩擦阻力 Rf | 385.54 kN | 385.5 kN |

摩擦侧逐位一致 → 两边的 Holtrop 内核是同一个方法，不存在算法分歧。

## 已排除的三个嫌疑

1. **湿表面积口径**：plimsoll 允许传入几何积分面积，但改用回归值时总阻力只变 **1.4 %**（1,039.4 → 1,025.4 kN），排除。
2. **形状因子**：两边取值一致（1.1225 / 1.123），排除。
3. **QPC 假设**：把 plimsoll 的 EHP 折成 ssr 报出的 37,969 hp，需要 QPC ≈ 0.32–0.40，对战列舰低得不合理，排除"同一转换口径下差 39 %"这一解释。

## 真正的原因

- plimsoll 的轴马力 = EHP / QPC，QPC 由调用方显式给出（本次 0.55），口径透明。
- ssr 的 `validate` 输出的是它**原程序经验轴马力拟合**的结果；它自己的 demo 明确写着
  *"Propulsion: original empirical shaft-power fit; no explicit QPC (the Holtrop-style efficiency breakdown is not used)"*。
  所以 37,969 hp 与 EHP/QPC 不是同一个量，不能直接比。

## 由此得出的两条工程结论

1. **因素不能直接搬**：ssr 的 22.44 % → 10.19 % 是在它自己的轴马力口径下算出来的；plimsoll 要复现，
   必须先用**同一个轴马力口径**（EHP/QPC 或原程序经验拟合，二选一）重算双方。
2. **几何合成会污染阻力**：plimsoll 的参数化船体给出的 Cm 0.788 / Cp 0.706，而 Dreadnought 实际约
   Cm 0.97 / Cp 0.577；同一内核下总阻力因此从 844.5 kN 涨到 1,039.4 kN（+23 %），几乎全在兴波项
   （301.6 → 486.0 kN）。所以任何"对真船"的误差统计都必须喂**声明系数**，不能喂合成几何反算的系数。

## 下一步

1. 在 plimsoll 里加一个"声明系数"入口（或让阻力阶段接受 scenario 提供的 Cb/Cm/Cwp），使对标时两边系数一致；
2. 用同一轴马力口径重算 146 案例，得出 plimsoll 自己的 MAPE 与按舰种因子；
3. 才进入分段混合与 LOOCV。

## 第二批：plimsoll 自己的 146 案例误差（实测）

把 ssrcalculator 内嵌的 146 条历史案例（`core/src/accuracy.rs`，含 L/B/T、排水量、Cb、航速与参考轴马力）
逐条喂给 plimsoll 已移植的原程序口径：`co_sharp` → `effective_length_ft`（cruiser 艉型）→
`wetted_surface_sqft` → `speed_hp`（engine_year 取 1900，仅影响 1890 年前的年份惩罚）。

| 方法 | MAPE | 中位 | 来源 |
|---|---|---|---|
| **plimsoll 原程序口径（本次实测）** | **15.93 %** | **11.86 %** | 本仓库 `concept_estimates` |
| ssrcalculator 的"original" | 22.44 % | 15.26 % | 它的 `validate-regime` |
| Holtrop 未校准 | 19.16 % | — | 同上 |
| Holtrop + 按舰种因子 | 10.19 % | 7.65 % | 同上 |

按舰种（plimsoll）：巡洋舰 10.6 %（n=44）、航母 10.7 %（n=32）、战列舰 14.4 %（n=32）、驱逐舰 **27.8 %**（n=38）。

### 三条结论

1. **plimsoll 的移植比同源移植更接近原程序**：同一批数据、同一口径，15.93 % 对 22.44 %，
   差 6.5 个百分点；连 Holtrop 未校准（19.16 %）也不如它。
2. **驱逐舰段没有想象中糟**：早前按 ssr 的口径看到 T-G 血统 43.7 %，plimsoll 实测只有 27.8 % ——
   说明那 43.7 % 里有相当一部分是**移植差异**，不是方法本身的极限。
3. **仍然需要校准**：只有 ssr 的"Holtrop + 舰种因子"（10.19 %）胜过它，说明按舰种纠偏仍有空间；
   但纠偏的基线应当用 plimsoll 自己的 15.93 %，而不是 22.44 %。

### 口径与保留

- 参考轴马力本身 0/146 经官方试航或水池验证（原作者标注），所以这些数字是**相对参考**的误差，不是绝对精度。
- 本次把 `displacement_tons` 视作长吨、艉型统一取 cruiser，engine_year 取 1900；三项假设都会进入误差，
  已记入本文件的复现说明。
