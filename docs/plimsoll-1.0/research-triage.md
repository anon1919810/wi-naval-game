# 后续算例与方法的资料核对记录

日期：2026-09-22。用于 Task 3 / Task 7，表示已发现的风险和资料入口，不表示新算法或案例已完成。

## 从当前源码与案例直接发现的风险

1. `queen_mary_1913_guns.json` 的 Mark II 炮座 `mount_weight_t=600.0`，同一条来源字符串却写 `600 tons (610 mt)`。canonical 公吨输入不能直接沿用 600；应核对原始吨制及四座 Mark II* 的替代假设。
2. 同一案例分别计炮重与炮座重，炮座来源的包含边界不明确。在没有证实前，不能宣称已排除炮、旋转装甲或机构的重复计重；Task 3 采用的估算边界须列成表，并通过共同 ownership token 防重。
3. 副炮 `broadside_guns=16`，注释承认没有考证。它不是已经验证的单舷齐射数；与左右各八门布置相冲突，后续应据布置角验证并标记。
4. `gen_weights_case.py` 以包围盒面积及全板厚度估装甲重；特别是甲板和炮座，包围盒不能自动证明真实覆盖。数据可以作为模型估算，但不要称“实数据”或“史实重量通过验证”。
5. 旧 `COVERAGE.md` 以计算能力/测试条数宣称差异化完成 100%，以及把 Holtrop 限定为民船，均已撤销。现有函数还需同载荷、有效性、时间线和发布验收。

## 首轮外部检索

- [Holtrop & Mennen (1982), 期刊正式记录](https://journals.sagepub.com/doi/10.3233/ISP-1982-2933501)：作者、刊期及 166–170 页可核对；全文受访问限制，本轮未购买或登录。
- [MARIN 原研究机构摘要](https://www.marin.nl/en/publications/an-approximate-power-prediction-method)：明确包含细长军舰扩展，并提示小样本与相似船型的限制；不能从摘要推得 Queen Mary 完整适用范围。全文下载需账户，本轮未注册。
- 搜到原论文扫描转载入口，但尚未逐页核对。Task 7 必须找到可合法阅读的论文版本、确认公式版本并固定数值基准，不能以摘要或搜索片段直接写计算。
- 搜到 [1912 年 The Engineer 扫描](https://graces-guide-s3-live.s3.amazonaws.com/gracesguide/2/2b/Er19120712a.pdf) 与 [美国海军 S-584-015 设计重量表说明](https://shipscribe.com/styles/S-584/images/s-file/s584015c.htm)，本轮抓取失败。它们只作为待查入口，未从中采用 Queen Mary 数值。
- Queen Mary 检索易混入 1936 年同名客轮；此类船体/机械重量资料全部排除，不能作为 1913 年战巡数据。

## 下一步约束

先区分资料直接值、模型几何推导、经验式和明确工程假设。对查不到的舰体结构、锅炉/主机、舾装及 CG 采用可调整的计算或估算区间，并公开未分配质量。不得根据目标总吨位反算一个“其它”组填平差额。

在比对 SPS 前固定同一船型、同一单位、同一加载条件、同一方法版本以及容差。字段齐全不证明算法精度；方法不同也不能仅凭输出更接近期望值宣布更优。
