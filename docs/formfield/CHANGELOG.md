## 已随 `0add0b4` 发布 — 第三组功能转场（实现日期 2026-10-06）

**2026-10-07 已提交、推送并部署。** 上一生产版本为 `7131a78`，下方保留本功能簇实现与验收记录。

- **读取反馈共用一套**：按 library/workbench/run/report/workspace 各自的结构给出静态细线形状（列表行、章节索引与输入格、运行身份与阶段卡、报告封面与六项读数格与窄索引），装饰形状约 150ms 后出现，快读取不闪烁，两秒后补上仍在等待的对象。形状不扫动、不带真实答案没有的数字。
- **读取失败与创建失败分开**：读取失败同时结束骨架与「读取中」计数，给出原地重试，创建入口保持可用；创建失败只在创建处说明。
- **连接、运行与报告读取失败可原地重试**：App 重试先问 `/me`，401 才建立工作区，且保持 single-flight，不自动重复写请求。
- **工作台动作分别命名** saving / starting / reloading；保存期间 Run 控件不再被标成运行忙碌；保存期间新增的修改保留 dirty，409 复制与重载路径不变。
- **生命周期归属**：已被取代或已卸载的请求不得写入已消失的树、不得导航；运行页轮询失败仍保留旧结果与独立的取消错误。
- **转场**：章节 150ms、Trace 180ms、Library→Workbench 与 Run→Report 220ms，全部为局部 CSS 动效，不重挂持有草稿的容器，不逐键触发动效，不截图或变形长报告正文。页眉在转场期间始终显示当前位置。
- **离开保护**：未保存时离开项目库、公共站点、其他项目与浏览器返回/前进均需确认；章节、Trace、单位与报告锚点不询问；仅 dirty 时拦截关闭标签页。
- **Splash 每浏览器会话一次**，页脚 Replay 可重播，sessionStorage 被拒时正常降级。
- **懒加载工作空间模块失败可恢复**：给出真实页面重载（失败导入会被浏览器的模块映射记住，故只有新的文档能重新获取该块），并保留公共页面返回；公共页面不受影响。

独立验证：前端全量回归 **21 个文件、353 项全部通过**（基线 18 文件 296 项；本轮新增读取反馈与恢复 26 项、转场与动效 17 项、离开保护 14 项）。TypeScript/Vite 构建通过，`git diff --check` 通过。浏览器人工验收由 Codex 独立进行：两种桌面宽度的浅深色、读取骨架布局与无横向溢出、reduced-motion 下计算样式确为 `none`、以及冷启动拦截工作空间模块时的失败面板与恢复路径。

220ms 路由进入采用局部 CSS 揭示而非命名组 morph：命名 morph 需要对整页截图，一份报告可达数千行，快照既昂贵也会把长正文变形；代价是工作空间页面之间没有共享元素形变，身份连续性由页眉的当前位置承担。
