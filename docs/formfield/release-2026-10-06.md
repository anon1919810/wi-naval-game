## 回滚

本轮只切换静态站点，回滚同样只需原子切回链接。nginx 配置未改，无需 reload：

```bash
target=/opt/plimsoll/releases/plimsoll-web-20261004T025804Z-6dea93c
ln -s "$target" /opt/plimsoll/current.next
mv -Tf /opt/plimsoll/current.next /opt/plimsoll/current
curl -fsS https://119.91.211.156/api/health
```

**本轮不需要数据库回滚**：未执行迁移，结构与数据未被本轮发布改动。运行时发生变更、需要重建容器时的完整回滚见[生产运维手册](../plimsoll-1.0/web-production-operations.md)「回滚」一节（`cd` 到旧发布目录 → `compose up -d` → 切链接）。禁止 `docker compose down -v`，它会删除 `plimsoll_db-data` 卷。
