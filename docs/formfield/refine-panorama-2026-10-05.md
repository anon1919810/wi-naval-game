## 层级、视差与光标（本节为第五轮追加）

- **线宽三级**：主轴线 1.4（虚线十字）、主辅助线 1.1（斜线/圆弧/L 框/玫瑰外圆/注册点）、细部 0.75（站位/刻度尺/玫瑰刻线/虚线基准圆）。
- **数字刻度**：刻度尺长刻上方标注 10…90（相对单位，非真实测量）；站位线顶端标注 S1…S8。均随图板旋转，位置选在 −12° 静止角下不出画框的区域。
- **双层视差**：`Artwork` 拆为 `ff-layer-geometry`（图板）与 `ff-layer-vessel`（线图）两层；展台内鼠标/键盘平移时图板只走线图位移的 45%（`GEOMETRY_PARALLAX`），形成轻微浮动错位。开场动画两层同角度同缩放同步绘制，收整无错位。遮罩跟随图板层，极端平移下线稿与遮罩最多错位约 50 构图单位，视觉上不可辨。
- **定制光标**：展台内隐藏系统光标（`cursor: none`），替换为蓝图十字准线——accent 色细十字（38px）+ 26px 描边环 + 3px 中心点，与 Inspect 标记同一语言。仅鼠标指针显示；触摸不显示；Inspect 开启时让位给 90px 大标记；展台外恢复系统光标。位置更新走 rAF 直写 DOM，不经 React state。

- **遮罩跟踪（第六轮修正）**：用户发现视差平移时辅助线露出船形缺口。原因是甲板遮罩静止于图板坐标系。修正：遮罩内的舰体剪影包在 `.ff-mask-track` 分组中，按线图层在图板坐标系的实际位移 `R⁻¹(pan × 0.55)` 同步平移（R⁻¹ 为 −12° 静止角的逆旋转），线图移到哪里，裁切跟到哪里，图板其余部分保持完整。测试断言 ArrowRight 后遮罩位移 `translate(8.07 1.72)`。

- 02 的甲板底色由过深（中位 147）提至 184，并只在底色区间内做降噪平滑，不伤墨线；03 的灰度填充同步协调。两幅的填充特征保留，仅收敛到统一观感。

## 改动内容

1. **展台全景化**：构图 viewBox 由 `1600×900` 改为 `1600×700`（16:7），构图中心 (800,450) → (800,350)。船带占帧高由约 26% 升至约 34%，桌面端船体渲染尺寸约 +31%，源图放大倍率仍约 1.1×（接近原生分辨率）。全部几何辅助线绕中心按 0.78 系数压缩重排，保持原有相对关系。`Splash` 收整位置跟随展台，无需单独调整。
2. **浅色墨线压实**：`InkFilter` 的 tone curve 按主题分参——浅色 slope 1.2 / intercept −0.05，深色维持 1.08 / −0.035（深色已有整体 opacity 0.85）。原因：等密度下深墨浅底比浅墨深底视觉更弱。
3. **浅色辅助线保底可见**：几何组 opacity 浅色 0.2→0.27、网格块 0.55→0.70，深色不变。修复浅色下 Geometry 开关几乎无视觉差别的问题。
4. **CSS 展台尺寸**：`.ff-exhibit` 由固定 `height: clamp(320px, 51vw, 570px)` 改为 `aspect-ratio: 16/7; max-height: 620px`，消除宽屏下 SVG meet 产生的左右死边；移除 `@media (min-width: 1800px)` 特例；移动端 `height: 330px` 不变（height 明确时 aspect-ratio 不参与）。
5. **小修**：移动端（≤650px）隐藏 exhibit 右侧装饰标签（原断行把 "01" 单独甩到第二行）；主题下拉改为 `appearance: none` + 自绘 chevron，去掉原生系统箭头。
6. **微调**：`TOP VIEW / REFERENCE` 标签移至 (180,560)、左下网格块高度 131→115——全景画框压缩后原坐标在 −12° 旋转下越出画框底边。
