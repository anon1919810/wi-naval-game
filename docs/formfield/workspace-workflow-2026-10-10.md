# Plimsoll 工作空间流程 · 2026-10-10

本说明覆盖 CLI 内置指南、诊断定位和项目备份恢复。实现已经本地验收；具体生产发布记录另列于[更新日志](CHANGELOG.md)，本页不把本地完成等同于上线。

## 保存与恢复项目

工作台下载的项目 JSON 是输入备份。清除浏览器 Cookie 或换设备后，在新的匿名工作区进入项目库，选择「从备份恢复」的 JSON 文件。服务端先校验原始项目并返回名称、来源 ID、修订、几何种类、输入数量和诊断，预览不会创建项目。

确认新项目名称，再点击「保存为新项目」。服务端重新校验，生成新 UUID，归属当前工作区，从修订 1 开始。原项目不会被覆盖；型线、条目 ID、来源、估算、未知值和已知零保持其输入语义。导入不恢复旧运行、缓存或计算结果，不自动提交计算。

UTF-8 JSON 可带一个 BOM。文件与实际请求体均受 8 MiB 限制；不可解析、非有限数字、错误的原始身份/修订和外部几何引用会被拒绝。运行页 JSON/CSV 是计算报告，不是项目备份。保存失败时保留预览和名称，允许重试；取消或换文件会结束旧预览的归属。

## 从诊断修正输入

概览并列展示当前请求选中的阶段和已保存的上一次检查，后者明确注明运行、修订与工况。保存新修订后，旧诊断仍可作历史参考，不证明新请求已经有效。数值结果继续要求项目、修订、工况匹配且草稿无未保存修改。

报告中的已识别诊断可到达实际船型或重量字段。重量条目按来源快照中的 ID 映射到现有条目，重排不改变所指对象；删除条目和外部项目不产生错误定位。没有独立表单的输入会进入项目数据并保留原始路径；请求参数进入对应请求区域。未知或结果路径只保留证据。

定位不会改值、保存或自动运行。未应用的项目 JSON 受到离开保护；用户显式保存修订、重新运行后，结果才属于新的输入。旧报告和导出保持不可变。资料不足、未请求、数值失败、模型越界和取消有各自含义；「暂不可计算」保留具体原因。

## CLI 指南供 AI 读取

仓库运行前把 `tools` 加入 `PYTHONPATH`，执行 `python -m plimsoll readme`。命令把固定包资源 `CLI_README.md` 的 UTF-8 字节写到标准输出，不读取项目、不生成文件、不计算，也不访问网络。

指南说明真实命令和退出码、15 个阶段、四轴有效性、规范单位、指纹、`null`/`0` 和来源/估算。AI 应据此解释已有 JSON/CSV，追问缺失输入并保留不确定性；计算完成不代表实船精度或工程认证。

## 网站资源与发布前验证

公共导航在窄屏统一缩放并允许换行；正文次级颜色为 `#6C6F6A`，VIEW PROJECT 有 44px 实际点击高度。参考图使用逐像素相同的无损 WebP，仅加载所选图纸；音效延迟到启用后的真实交互。手动主题继续保留。

Nginx 模板压缩 JS/CSS 等文本资源，补齐 WAV/WOFF2 的 MIME 与静态缓存，缺失的真实路径返回 404。网页增加分享元数据、canonical 与 favicon；备案未包含在本轮。

发布前独立复核：前端 36 文件、638 项通过，TypeScript/Vite 构建通过；后台 103 项通过，另在独立 PostgreSQL 上执行两项并发专项并通过；CLI/包导入/导出 48 项及 27 个子测试通过。打包器 Windows 18 项通过、1 项因符号链接权限跳过，生产 Linux 补验另见发布记录。

发布审查补正了一处请求显示：有效破损请求的进水阶段已进入实际请求，却曾被就绪列表遗漏；列表现在读取同一份提交请求。新增行为用例先复现失败，修正后诊断簇 43 项与完整回归通过。

此前实机验收包括 320/390px 公共页面、桌面浅深色、真实诊断修正后重算、旧导出保留、原生文件选择与 2.7 MB 备份保存重开。原生保存失败拦截没有成功阻止请求；失败保留与重试由组件测试覆盖，不把它写成原生浏览器已验收。
