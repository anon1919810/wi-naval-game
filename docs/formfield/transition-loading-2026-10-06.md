## 交付行为

- 项目库、编辑页、运行、报告和连接等待共用结构化读取占位。装饰约 150ms 后出现，超过两秒补充仍在等哪个对象；读取就绪立即显示，不用最短 loading 时长拖延数据。骨架静态，无扫光、虚构百分比或 ETA。
- 项目库读取失败结束骨架和读取计数，提供原地重试；创建失败单独显示，模板与空白创建仍可操作。App、Workbench、Run、Report 有明确读取恢复入口。
- 连接重试先读取现有身份，仅 `/me` 返回 401 时建立匿名工作区；连接、读取、创建、保存与启动运行的迟到响应都检查生命周期或请求归属。不会自动重复写请求。
- 保存、启动计算、重载分别显示真实动作；保存期间继续编辑的内容保持未保存状态，409 复制草稿与重载语义保留。运行活动标记只对应服务端 queued/running，终态移除，取消请求与实际结束分开。
- 章节切换 150ms、Trace 内容 180ms、工作空间页面进入 220ms。工作台容器保持挂载；同章节和同字段值更新不重播。连续路由切换通过交替动画名重启，最新切换优先，长报告不做整页快照变形。
- 未保存离开在动画和地址提交前确认；取消后保留草稿和地址。原生链接只确认一次。浏览器历史条目记录 session/index，取消 Back/Forward 用实际位置差返回原条目，不改写目标地址；重复 URL、多步历史和新分支均有验证。章节、Trace、单位与同项目片段不询问，刷新/关闭仅 dirty 时提醒。
- Splash 每浏览器会话自动一次，Replay 可重播；sessionStorage 被拒时正常降级。
- 工作空间模块失败提供真实页面重载与公共返回。浏览器缓存失败的 import，创建新 lazy 实例不能重新下载；重载用新文档恢复，并读取现有身份。占位和失败样式在 main 入口提前加载，冷模块故障时仍有正确布局及 Space Grotesk / Inter 字体。
- reduced-motion 覆盖位于 CSS 末尾；章节、Trace、页面进入、读取装饰与运行环均静止。打印不运行动画。
