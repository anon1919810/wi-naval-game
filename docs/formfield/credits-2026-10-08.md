## 本地连接修复与启动入口

- 根因：5173 前端运行，但 8000 无 API 监听，Vite 代理报 `ECONNREFUSED` / 502。复用既有隔离 SQLite 数据库，未建库、重置或迁移。
- 新增 `web/dev/start-local.ps1`（PowerShell 7.4+）及 `anonymous_api.py`：从仓库根目录运行 `pwsh -File web/dev/start-local.ps1`。可用 `-DatabasePath` 指定已迁移的现有 SQLite 文件；API 已运行时不允许以该参数暗中换库。
- API 与前端仅监听回环地址；启动前只读验证既有库，识别 API 服务名与匿名模式、Vite 页面及其代理响应。重复运行复用健康服务，端口被其他服务占用则报错；无进程终止、环境变量持久修改或生产配置访问。
- Codex 实测：API/Vite 冷启动成功，重复运行保留监听 PID；直连及代理健康/匿名模式返回 200；从标题入口实际进入项目库。缺失、空白、损坏的数据库均被拒绝，未创建或修改数据文件；检查后连接句柄关闭。占用端口的拒绝路径经代码审查，未另外启动冲突服务模拟。
- 本脚本仅提供浏览和编辑预览。计算 worker 仍按本地运行文档单独配置启动。
- 音效扩展仅讨论；用户已选“操作用仪器触感，转场与完成用柔和玻璃”，见 [音效讨论](interaction-sound-design-2026-10-08.md)。
