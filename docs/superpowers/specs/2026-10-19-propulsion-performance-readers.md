# 动力、续航与性能阅读闭环

## 目标

把原版已有的动力、续航、稳性、强度和适航性读数现代化为普通章节中的解释视图，并将同一读数纳入冻结报告及比较。保持一份原生设计、一套已有计算结果和重量台账；不引入新物理方法。

## 范围

动力章节先展示燃料 → 主机 → 传动 → 轴数的声明链，使用既有双语枚举表。最大／巡航航速与对应来源马力配对，续航以 nmi 表示；没有完整曲线数据，不画曲线。煤比例、正常／最大载煤燃油重量保持来源单位 long ton (LT)。两条全舰角色 machinery、fuel 显示 estimate_t、selected_mass_t、策略及未绑定状态，不向设备或燃料类型分摊。

锁定状态来自结果自己的 design.editing.power_locked、power_hp、locked_bunker_lt（不能读当前宿主替代冻结结果）。严格区分 true、false、缺失。说明现有“重算功率／航速”按钮调用源求解器；锁定不等于界面实时求解承诺。未知锁定目标不显示为 0。

性能章节按稳性、船体强度、适航性三组展示：stability、stabilityAdj、metacentre、rollPeriod；strengthCross、strengthLong、strengthComp；seaboat、seakeeping、steadiness、steadinessAdj。保留各自来源单位，经验得分不当作现代物理 GM 或安全认证；metacentre 明确为来源经验推算的高度。以源布尔值 tenderWarn、capsizeWarn、steady、unsteady、badSea、poorSea、goodSea、fineSea 展示源判词，true／false／未知分别呈现，不在浏览器重新定义阈值或制造总分。未有警告不等于设计已安全。

说明与相关输入必须诚实：性能受船体、干舷、装甲、武备、重量和 trim 等声明影响，提示只指向相关输入，不保证调大某数能解决。性能页支持直接定位 trim；其它相关项可打开相应章节。动力的航速、航程、轴数、煤比例等按钮必须揭示并聚焦真实字段；不设置任何设计值。冻结报告没有编辑或跳转按钮。

冻结报告复用两个视图，显示运行身份与只读提示。不得调用预览 API。遵守 requested、父阶段状态、原生 schema、method 与声明的 kernel 一致性；失败或不支持的数据即使残留数值也不展示。部分结果可逐字段读出，缺失值为未知。草稿 pending／failed 完全隐藏旧数值与操作。

冻结比较沿用当前与对照身份／条件／方法／单位有效性闸门，方向仍是对照减当前；增加巡航航速、巡航马力、横向与纵向强度、适航性、来源经验高度及横摇周期的读数，不增加重复的源表格或另一套比较规则。冻结配置表增加轴数、航程和严格的功率锁定声明／目标，均来自各自的冻结结果。不混入实时输入。
