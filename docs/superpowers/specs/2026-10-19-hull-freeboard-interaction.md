# 船体与干舷交互化

用户已授权自主设计并执行长任务。前置发布完成：动力／性能源码 1ee8415 已上线，发布记录 cc194c2 已推送。当前工作树干净，本轮在原位置实现并集中验收，完成后保留为本地候选。

## 目标与使用效果

普通船体章节先说明已有联动结果：水线长、总长、型宽、防雷突出部宽、正常吃水、方形系数及来源正常排水量；显示结果自己保存的长度驱动、排水量驱动与深度锁定状态。长度驱动只识别 waterline／overall，排水量驱动只识别 block／displacement；缺失为未知，不能用控件默认值填补读数。来源排水量保持 LT；统一台账的目标与差额保持原有单位身份，不从主尺度重新计算体积或重量。字段按钮只定位真实存在的输入，驱动切换继续使用上方原有控件。

普通干舷章节提供可选择的八端点剖面及完整端点清单。鼠标或键盘选中端点，再通过明确的编辑按钮揭示并聚焦原字段；选择本身不写设计。清单使重合端点仍可分别选择。图形按已有 freeboardProfileModel 映射，表示已声明端点及相邻线段，不表示实际型线、真实船艏外形或防护面积。负干舷是已知来源值，正常绘出；未知不代填 0。站位所需长度、比例、角度或艉延伸缺失／非有限时不给虚构轮廓，仍列出独立已知端点与读数；比例明显无效时说明轮廓不可绘制，不夹限或重写数据。

八端点顺序沿用 FREEBOARD_ENDPOINTS：freeQDAft、freeQDFor、freeADAft、freeADFor、freeFDAft、freeFDFor、freeFCAft、freeFCFor。其原字段分别是 freeboard_quarterdeck_aft／fore、freeboard_afterdeck_aft／fore、freeboard_flat_deck_aft／fore、freeboard_forecastle_aft／fore。长度源值为 ft，显示跟随现有单位控件。fcLength／fdLength／adLength／qdLength 是 0–1 比例，显示为百分比；lengthBow 是角度（deg），不是长度。

深度锁定按源语义说明：快照来自 design.editing.depths；FD／AD 四个端点被锁定时，新增图解不提供可执行的编辑按钮；FC／QD 的输入可能由源快照重算覆盖。齐平／抬高预设仍使用现有命令；锁定时快照优先，不能承诺按钮必然改变轮廓。不增加拖拽改值、自动解锁或新几何计算。

原目录把 freeboard_length_bow 列在长度尺度字段中，但 sps_hull.py:325、112 中该值明确是角度且不作长度换算。本轮只在前端 resolvedUnit 中修正这个字段为 deg，保留原命令、源目录、项目字节与计算行为；中英标签已是 Bow angle／艏角。

## 草稿、报告与图片

- 支持的原生 schema／method 与 payload available／partial 才可读。pending／failed 时隐藏新视图的数值、图形、定位和导出。未知、false、0 各自保留。
- baseline 是宿主已经取到的同工程保存结果。仅支持的方法、状态与同一已知 basis 可以标出端点变化；按规范化源值比较，保存刷新 baseline 后高亮消失。两边未知不算改动，已知变未知需显示变化。
- 冻结报告复用相同船体读数、剖面和八端点清单，明确运行身份，只读且无编辑／选择控件，不请求预览。复用现有 envelope gate，并独立校验 native schema／method／status。非原生兼容报告继续使用原 SpsFreeboardProfile，不改其行为。
- 原生剖面保留 PNG 下载，并增加同内容 SVG 下载；复用现有 SVG／PNG 下载工具，文字、单位、白底、颜色、命名空间与运行身份自包含。导出包含所有八个端点，选择某个端点不能删掉其它信息；失败要有反馈。选中状态不应销毁正在获得键盘焦点的 SVG 节点。
- 冻结配置比较保持原来的项目／方法／basis／有效性闸门与对照减当前方向。补充来源 LOA、Cb、排水量、两个驱动和深度锁定，以及八个端点和四段比例；已有 16 项摘要读数不扩成另一个大面板。输入、锁定来自各自冻结结果。源量未知时差值未知。

## 设计与边界

继承现有工作台的制图语言、字体和主题；图像本体使用清楚的线、端点、变化标记与水线，说明和编辑面板沿用现有卡片。390px 时图在自身容器滚动，清单与操作可换行，页面不横向溢出。文字不压在相同坐标的端点上，可用清单／选择说明承担详细标签。PNG 与 SVG 内容一致。
