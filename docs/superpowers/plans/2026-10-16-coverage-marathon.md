- Planar plates must work without unrelated hull context; source box-deck zero selected loads retain their source margin.
- Missing fore/quarter deck layers and missing load roles must remain unknown.

- Import must preserve exact source bytes and both existing mount-group identities while adding fixed declarations safely.
