## 阶段 2 · 浮态自由度：加上纵倾

现在 `solve_waterline` 只能平移水线，不能倾斜 —— 船会纵倾，战损尤其。

- [ ] **2.1 积分器支持纵倾**：水线在 x-z 平面成为斜线 `z = x·tanθ + d`，
  逐站截距 `d(x) = d + x·tanθ`。剖面内的切削逻辑不变。
  验收：方箱带纵倾角的解析解（等体积纵倾）逐位吻合。
- [ ] **2.2 纵倾平衡求解**：给定排水量与 LCB(=LCG)，解出 (d, θ) 使体积与纵向力矩同时平衡。
  验收：方箱 + 一个已知纵倾的案例；迭代收敛且稳定。
- [ ] **2.3 水线长与排水量的耦合检查**：大纵倾下 LWL 会变，须交代其对结果的影响。

## 阶段 3 · 自由液面修正（FSC）

进水舱的自由液面会显著抬高重心等效位置。

- [ ] **3.1 单舱自由液面惯性矩**：由舱室几何算液面惯性矩，`FSC = Σ(ρ_i·i_i)/(Δ)`。
  验收：矩形舱解析解。
- [ ] **3.2 并入 GM 与 GZ**：修正后的 KG 用于稳性曲线。
  验收：与未修正版本对比，量化差异。

## 阶段 4 · 破损稳性（**阶段性目标**）

这是 Plimsoll 真正要交付的能力，也是游戏侧进水系统最终需要的东西。

- [ ] **4.1 进水组合模型**：给定若干舱室进水 → 增加的重量与重心（含自由液面）。
- [ ] **4.2 新浮态求解**：解出破损后的 (吃水, 纵倾, 横倾)。
- [ ] **4.3 剩余 GZ 曲线**：在新浮态附近重算 GZ，给出稳性范围与最大复原力臂。
- [ ] **4.4 场景回归**：单舱/双舱/中纵舱进水，结果可复现并落盘。
