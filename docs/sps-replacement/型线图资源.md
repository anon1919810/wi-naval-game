## 1. 书：John Roberts《Battlecruisers》（**首选，最实际**）

| 项 | 内容 |
|---|---|
| 版本 | Chatham 1997 首版 `ISBN 186176006X` / `9781861760067`；Caxton 重印 `1840675306` / `9781840675306`；USNI 1998 `9781557500687` |
| 规格 | 128 页，4to 大开本（约 29 × 25 cm） |
| 已知内容 | 两家独立书商描述都明确写「**folding plans of HMS Queen Mary 1913**」（Biblio）／「large scale plan... loose fold-out plan」（IberLibro） |
| 二手价 | 约 **$11–20**（Alibris / Abebooks / Biblio / IberLibro 均有货） |

**确认程度**：
- ✅ 书存在、有 Queen Mary 的折叠大图 —— 两处独立书商描述证实
- ✅ 一位 1/700 模型制作者称该书图纸"除总布置与侧视图外，**还有各站位的横剖面**"
- ❓ **那张大图是「型线图（带水线）」还是「总布置图（侧视+甲板）」—— 未确认，需拿到实物**
- ❓ 所谓横剖面是**船体型线剖面**还是**布置剖面** —— 未确认

若为真型线，可直接转成 `hull_offsets.json`；若只是总布置，则只能用于校核干舷与型宽。

## 2. 英国国家海事博物馆（NMM）在线目录

- 检索：`https://www.rmg.co.uk/collections/object/search/<关键词>`
  可按 Item Category = `Ship Plans and Technical Records - Admiralty Collections` 筛选
- **已找到 NPN7801**：<https://www.rmg.co.uk/collections/objects/rmgc-object-573568>
  - 「HMS Queen Mary (1912)，比例 **1:96**，a plan showing the **profile, sections and part deck plans**
    illustrating the **distribution of armour and protective arrangements**」
  - Type: Technical drawing；Credit: © Crown copyright, NMM
  - **带剖面，但主题是装甲布置 —— 不是型线图。** 对 L4 装甲分区有参考价值
- **未找到专门的型线图（lines / body plan）**。检索 "queen mary" 共 827 条结果
  （两代 Queen Mary 混在一起），细分未穷尽；**目前没有证据表明 NMM 藏有本舰完整型线图**
- 另见 **SLR1408**：1:48 建造者全船模型，长 **4.475 m**（当年赠予玛丽王后本人）。
  可作外形参照物，**不是可用的型线数据源**
- **NMM 出售图纸复印件**：<https://prints.rmg.co.uk> —— 高分辨率母版印制，2–4 天发货，
  按幅面计价（示例：HMS Monarch 1868 的 inboard profile 约 £81）

## 4. 附带解决：水线长（LWL）的取值

多源核对结果（此前 Plimsoll 案例里取错了，见下）：

| 来源 | 舰长 |
|---|---|
| worldwar1.co.uk | **698 ft waterline** = **212.75 m**；703 ft 6 in overall = 214.4 m |
| 维基 Infobox | 700 ft 1 in = 213.4 m |
| Navypedia | 214.4 m（总长） |
| MaritimeQuest | 700 ft |
| ThoughtCo / 快懂百科 | 703 ft 6 in = 214.4 m |
| Tyne Built Ships | 675.0 ft = 205.7 m ← **孤例** |

**结论：LWL ≈ 212.8 m，LOA = 214.4 m。** 与本项目模型（全长 213.4 m）相差 **0.3%**，
即**模型尺度是可靠的**；此前 Plimsoll 案例里的 `lwl_m = 205.7` 采信了孤例来源，**应改**。

排水量来源间有正常出入（标注即可，不必调和）：
Navypedia/Tyne 26,770 / 31,650 t；worldwar1 26,780 / 31,486 t；ThoughtCo 27,200 t。
