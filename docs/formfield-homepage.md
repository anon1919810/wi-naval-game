## 使用

在 `web/frontend` 运行：

```powershell
npm run dev -- --port 5173
```

打开 `http://127.0.0.1:5173/`。每次加载首页播放开场；站内 Work/About、浏览器 Back 和从 Plimsoll 返回不重播。底部 **Replay Intro** 可重看；Escape 或 Skip Intro 可跳过。系统减少动态效果偏好会直接进入展台。直接打开 About 或旧工具链接也会跳过首页开场。

**Reference 01/02/03** 切换三幅用户原始参考位图的下半俯视裁切带。Geometry 控制构成线；Inspect 显示探索焦点；鼠标移动、触屏拖动或方向键移动画面，Home/Reset view 复位。Inspect 当前是焦点标记，不是舰船参数查询或放大镜。Light/Dark/System 在本浏览器保存，与 Plimsoll 的服务端主题设置分开。

**Explore Project** 进入真实 Plimsoll 应用；原有 `#/projects/...`、`#/runs/...`、`#/reports/...` 保留。公共页面不加载计算应用或调用工作区认证 API。工具页需要另行启动原有后端（Vite 的 `/api` 代理仍指向 `127.0.0.1:8000`）；此次仅启动前端预览，实际计算与保存未做联网验收。

## 实现与素材

- `web/frontend/src/portfolio/Portfolio.tsx`：公共界面、主题和应用入口。
- `VesselDrawing.tsx`：直接显示三幅原 PNG 的俯视区域，以源坐标 clipPath 严格裁剪。保留炮塔、设备、排线和原有灰度，通过温和亮度转透明度处理净底、增强墨线；未进行超分辨率或几何重绘。透明区域受 SourceAlpha 限制，避免反色产生黑边。`Artwork.tsx` 保留几何装饰与甲板遮罩。原图文件不变，显示效果仍受原始分辨率限制。
- `Splash.tsx` / `motion.ts`：同一构图的两个注册一致的扫描层；100 / 800 / 200 / 700 / 700 ms，最后由 -28° 收整为 -12°。不使用虚假加载百分比。
- `public/portfolio/PROVENANCE.md`：来源、裁剪范围与用途边界。几何装饰不表示测量值，三张图不标成同一艘舰的可靠规格。
