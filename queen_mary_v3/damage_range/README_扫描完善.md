## 测中已改的试验场模型（非最终战斗参数）

| 改动 | 原因 |
|---|---|
| 爆炸 blast 上限约 0.55，且 `strength*0.45/(1+d²/9)*遮挡` | 避免 direct+blast 恒等饱和到 1.0 |
| 弹体擦伤 direct：0.35（命中）/ 0.20（哑弹过舱） | 哑弹不应等同引信起爆毁伤 |
| 破片单样本贡献 8→12（再乘剩余预算比） | 让破片在未饱和时可观测 |
| 破片方向：分层球面 + **种子全圆偏置** | v1/v2 几乎无种子方差，扫不出稳定性差异 |

## 扫描暴露的模型缺口（待续完善）

1. **毁伤可分辨性**：仍需避免任何单因素「永远 1.0 / 永远 0」。
2. **引信物理**：延迟时间 vs 穿板时间未建模（穿板瞬时）。
3. **角度效应**：在预算悬崖附近速度主导，入射角不敏感；需事件级敏感度报告。
4. **模块拓扑**：试验箱不是 Queen Mary 真实舱段；`Feed_Pump` 未进主契约。
5. **主战斗未接入**：RangeSolver ≠ ShipHitResolver。
